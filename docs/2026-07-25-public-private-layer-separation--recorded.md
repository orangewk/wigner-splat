# 2026-07-25 公開層と非公開層の分離 — outreach 系文書の退避

状態: recorded（実施済み。方針は orange 判断）

## 何をしたか

`docs/outreach/` を公開リポの HEAD から外し、非公開の姉妹リポで管理する形に変えた。
併せて `.codex/`（エージェント作業ディレクトリ）を `.gitignore` へ追加した（issue #18 の残作業）。

## 線引き

除去の基準は「内部文書かどうか」ではない。**第三者が本人の同意なく登場するかどうか**である。

このリポの研究記録・実験ログ・自己批判的な提言・負けの記録は、公開されているほうが価値が高い。
「反証条件を先に宣言し、負けたら負けたと記録する」は公開層の流儀であり、隠せば逆に信用を損なう。
`docs/dreams.md`、`docs/research-log.md`、`docs/2026-07-12-science-recommendations--proposed.md`
（BB† の novelty を自分で割り引く追記を含む）はいずれも公開層に残す。

一方 outreach 草稿は、実在の研究者を実名で挙げ、接触の優先順位と反応の引き出し方を記述している。
文面自体は誠実で過大主張もないが、宛先本人からすれば「自分宛のメールの設計意図と優先順位が
公開されていた」ことになる。扱っているのは自分の失敗ではなく他人の同意の問題であり、
公開層の流儀の対象外と判断した。

## 履歴について

`docs/outreach/` は 2 コミット（`2f6fd5b`, `0173612`）の履歴を持ち、
`docs/2026-07-12-outreach-campaign--wip.md` も `4d0c2f2` で HEAD から消えているが履歴には残る。
**いずれも公開リポの履歴から読める状態は変わらない。**

履歴書き換え（filter-repo + force push）は見送った。理由:

- Zenodo に v0.1.0 がアーカイブ済みで DOI が振られており、そちらは不変
- 公開後に clone / fork された可能性がある
- 研究記録の provenance を壊す代償が、得られる効果に見合わない

したがって本件の目的は「過去を消すこと」ではなく「HEAD をきれいにし、今後を分離すること」である。

## 今後

第三者が登場する文書は非公開リポに置く。公開リポ側では `.gitignore` の
`docs/outreach/` がガードとして機能する。
