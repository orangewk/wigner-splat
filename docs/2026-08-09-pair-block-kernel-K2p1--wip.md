## 1. 設定と主張

F = B₁₂ + c₃e^{q₃}、B₁₂(t) := c₁e^{q₁(t)} + c₂e^{q₂(t)}(c_j ≠ 0、q_j 相異なる複素 2 次)、
pair held: β_B := sup_K|η| ≤ 1/8(η := q₂ − q₁)。K 長さ 1、E ⊆ K 長さ ρ。
**木包絡**: U_T(t) := max(log|B₁₂(t)|, m₃(t))、m₃ := log|c₃| + Re q₃。
(U_T > −∞ 各点: B₁₂ の零点でも m₃ は有限。)

**予想 K(2)+1(v0.1)**: ‖e^{−U_T}F‖_{∞,K} ≤ C_T ρ⁻⁴ ‖e^{−U_T}F‖_{∞,E}(C_T 絶対定数)。

設計性質(いずれも定義から直ちに):
- **天井**: e^{−U_T}|F| ≤ 2 が **exact** に成立(|F| ≤ |B₁₂| + e^{m₃} ≤ 2e^{U_T})。
- **phantom の根治**: pair が深く相殺すれば log|B₁₂| がそのまま下がる — 包絡が虚偽に
  膨れない。§3.6.0 反例の摂動族(q₂ = q₁ + 1/10 + δt²、c₁ = −c₂e^{1/10})は
  δ = 10⁻¹〜10⁻⁸ で一様に比 ≈ 2·10⁻⁴·ρ⁻⁴(数値、§4)— U_F では 1/δ 発散だった。
- W = 3 帳簿の保存(pair は質量 2 の block のまま、Taylor 剰余を独立 weight に数えない)。

  **Φ := c₁ + c₂e^{η} = c₂e^{w} · (η(t) − w) · E(z(t))**(恒等式)

### 3.1 抽象化 K2QV は偽(Sol 監査 2026-08-09 — 本線検算済み)

C(Λ_V)ρ⁻⁴ kernel」は**偽**。

### 3.4 QR4 基本恒等式(v0.3 — 確立、数値検証済み)

**補題 QR4-I(pair-block 有限差分恒等式)**: z 複素 2 次(α ≠ 0)、u := log(e^{z(t)} − 1) + p(t)
(p 複素 2 次、枝は任意 — 指数化で消える)、h > 0。x_i^{(k)}(i = 1,2; k ∈ ℤ)を
z(t) = 2πik の根とすると
  **e^{Δ³_h u} = Π_{k∈ℤ} Π_{i=1,2} ρ₃((t − x_i^{(k)})/h)**(絶対収束)。

*証明*: e^z − 1 = 2e^{z/2}sinh(z/2) = z·e^{z/2}·Π_{k≥1}(1 + z²/(4π²k²))(sinh の
Weierstrass 積)。log を取ると log(e^z−1) = log z + z/2 + Σ_{k≥1}[log(z² + 4π²k²) − const]。
z(t)² + 4π²k² = (z − 2πik)(z + 2πik) は t の 4 次多項式で根 x_i^{(±k)}。
Δ³ は 2 次多項式 z/2, p と定数を消し、各 log(t − x) には K2 §5.2 と同じ計算で
e^{Δ³log(t−x)} = ρ₃((t−x)/h) を返す。収束: log ρ₃(X) = 2X⁻³ + O(X⁻⁴)(検算:
ρ₃ = 1 + (2X+3)/(X⁴+6X³+12X²+8X))と根の遠隔性(下の QR4-T)で Σ_k |·| < ∞。∎
(数値: 基底ケース 9·10⁻¹⁶、完全版は N = 32→8192 で残差 1.15·10⁻⁸ → 4.6·10⁻¹¹ に単調収束、
ランダム 5 配置 ≤ 1.5·10⁻⁸ — qr4_convergence2.py。**符号規約は (t−x)/h**。)

**補題 QR4-T(tail の遠隔性と大きさ — 証明スケッチ + 数値)**: osc_K z ≤ 1/4 のとき
k ≠ 0 の根は z-空間で |z − 2πik| ≥ 2π − (π + 1/4) ≥ 2.89 の彼方にあり、t-空間でも
dist(x^{(k)}, K) ≳ √(2π|k|/|α| 級)。従って tail := Σ_{k≠0} log ρ₃ は
  **|tail| ≤ C_tail·h³、C_tail 絶対定数(数値: 0.05 級、h = 1/12〜1/96 で h³ 比一定)**。
係数 (α, β) は osc 条件で有界 — C_tail の絶対性の根拠。厳密な定数勘定は次工程。

**帰結(残る問題の正確な形)**: 深平坦(K2Q (c-i) 相当)では
Δ³u ≈ 0 ⇒ **近接零点データ(k = 0 の 2 根)の Πρ₃ が −tail を打ち消す必要**がある。
反証された C³ 抽象化との決定的差: tail は自由な摂動でなく **同じ z の係数の陽関数**
(近接零点を動かすと tail も連動)。従って SN/R2′ の再構築は 6 パラメータ族
(z の 3 + p の 3、正規化後実質 4–5)の**自己整合問題**になる。
相補攻撃(記録): 深平坦は Δ³u だけでなく u ≈ 0 自体を与える —
a(e^{z(t)}−1) ≈ e^{−p(t)} on J という指数型 ODE 剛性(有限次元族の超越性)も使える。
