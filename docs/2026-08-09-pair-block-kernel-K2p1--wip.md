## 1. 設定と主張

F = B₁₂ + c₃e^{q₃}、B₁₂(t) := c₁e^{q₁(t)} + c₂e^{q₂(t)}(c_j ≠ 0、q_j 相異なる複素 2 次)、
pair held: β_B := sup_K|η| ≤ 1/8(η := q₂ − q₁)。K 長さ 1、E ⊆ K 長さ ρ。
**木包絡**: U_T(t) := max(log|B₁₂(t)|, m₃(t))、m₃ := log|c₃| + Re q₃。
(U_T > −∞ 各点: B₁₂ の零点でも m₃ は有限。)

**予想 K(2)+1(v0.1)**: ‖e^{−U_T}F‖_{∞,K} ≤ C_T ρ⁻⁴ ‖e^{−U_T}F‖_{∞,E}(C_T 絶対定数)。

設計性質(いずれも定義から直ちに):
- **天井**: e^{−U_T}|F| ≤ 2 が **exact** に成立(|F| ≤ |B₁₂| + e^{m₃} ≤ 2e^{U_T})。
- **phantom の根治**: pair が深く相殺すれば log|B₁₂| がそのまま下がる — 包絡が虚偽に
  膨れない。§3.6.0 反例の摂動族(q₂ = q₁ + 1/10 + δt²、c₁ = −c₂e^{1/10})は
  δ = 10⁻¹〜10⁻⁸ で一様に比 ≈ 2·10⁻⁴·ρ⁻⁴(数値、§4)— U_F では 1/δ 発散だった。
- W = 3 帳簿の保存(pair は質量 2 の block のまま、Taylor 剰余を独立 weight に数えない)。

### 3.4 QR4 基本恒等式(v0.3 — 確立、数値検証済み)

**補題 QR4-I(pair-block 有限差分恒等式)**: z 複素 2 次(α ≠ 0)、u := log(e^{z(t)} − 1) + p(t)
(p 複素 2 次、枝は任意 — 指数化で消える)、h > 0。x_i^{(k)}(i = 1,2; k ∈ ℤ)を
z(t) = 2πik の根とすると
  **e^{Δ³_h u} = Π_{k∈ℤ} Π_{i=1,2} ρ₃((t − x_i^{(k)})/h)**(絶対収束)。

*証明*: e^z − 1 = 2e^{z/2}sinh(z/2) = z·e^{z/2}·Π_{k≥1}(1 + z²/(4π²k²))(sinh の
Weierstrass 積)。log を取ると log(e^z−1) = log z + z/2 + Σ_{k≥1}[log(z² + 4π²k²) − const]。
z(t)² + 4π²k² = (z − 2πik)(z + 2πik) は t の 4 次多項式で根 x_i^{(±k)}。
Δ³ は 2 次多項式 z/2, p と定数を消し、各 log(t − x) には K2 §5.2 と同じ計算で
e^{Δ³log(t−x)} = ρ₃((t−x)/h) を返す。収束: log ρ₃(X) = 2X⁻³ + O(X⁻⁴)(検算:
ρ₃ = 1 + (2X+3)/(X⁴+6X³+12X²+8X))と根の遠隔性(下の QR4-T)で Σ_k |·| < ∞。∎
(数値: 基底ケース 9·10⁻¹⁶、完全版は N = 32→8192 で残差 1.15·10⁻⁸ → 4.6·10⁻¹¹ に単調収束、
ランダム 5 配置 ≤ 1.5·10⁻⁸ — qr4_convergence2.py。**符号規約は (t−x)/h**。)

**補題 QR4-T(tail の遠隔性と大きさ — 証明スケッチ + 数値)**: osc_K z ≤ 1/4 のとき
k ≠ 0 の根は z-空間で |z − 2πik| ≥ 2π − (π + 1/4) ≥ 2.89 の彼方にあり、t-空間でも
dist(x^{(k)}, K) ≳ √(2π|k|/|α| 級)。従って tail := Σ_{k≠0} log ρ₃ は
  **|tail| ≤ C_tail·h³、C_tail 絶対定数(数値: 0.05 級、h = 1/12〜1/96 で h³ 比一定)**。
係数 (α, β) は osc 条件で有界 — C_tail の絶対性の根拠。厳密な定数勘定は次工程。

**帰結(残る問題の正確な形)**: 深平坦(K2Q (c-i) 相当)では
Δ³u ≈ 0 ⇒ **近接零点データ(k = 0 の 2 根)の Πρ₃ が −tail を打ち消す必要**がある。
反証された C³ 抽象化との決定的差: tail は自由な摂動でなく **同じ z の係数の陽関数**
(近接零点を動かすと tail も連動)。従って SN/R2′ の再構築は 6 パラメータ族
(z の 3 + p の 3、正規化後実質 4–5)の**自己整合問題**になる。
相補攻撃(記録): 深平坦は Δ³u だけでなく u ≈ 0 自体を与える —
a(e^{z(t)}−1) ≈ e^{−p(t)} on J という指数型 ODE 剛性(有限次元族の超越性)も使える。

e^z−1 の k = 0 零点を r_i⁽⁰⁾(存在する i ∈ {1,2}、重根は重複して数える)と書く。

**片側規約と near/far 分割**: 下で定める N_A と h := s/N_A を用いる。各 y ∈ S に対し、
y を含む長さ 6h の区間 S₀ ⊂ S と向き σ ∈ {−1,+1} を、全差分節点
`{t+jσh:t∈S₀,0≤j≤4}` が S に入るように取る。N_A ≥ 12 なので端点でも内向きに選べる。
正規化根を x_i(t) := σ(t−r_i⁽⁰⁾)/h とする。この規約では σh-差分の節点は x_i+j となり、
向き反転は主係数の符号だけを変える。R_SN := 10⁴ とし、
dist(r_i⁽⁰⁾,S) ≤ R_SN h ならその根を near と呼ぶ。near 根 x₁ について
  X₁ := R_SN+9、 𝔇₁ := (X₁+4)⁴
と置く。第二根が存在し、min_{t∈S₀,0≤j≤3}|x₂(t)+j| ≥
X₂ := (7𝔇₁)^{1/3} なら far factor へ送り、それ以外は二根 near として
  𝔇₂ := (X₂+11)⁴
を用いる。この規約により |d₃(x₁)| ≤ 𝔇₁、二根 near では
|d₃(x₁)d₃(x₂)| ≤ 𝔇₁𝔇₂ が S₀ 上で成立することを P4 で検算する。

**cleared numerator**:

- 一根 near では
    N₁(t) := n₃(x₁)−d₃(x₁) = 2x₁+3、  Q₁(t) := d₃(x₁)。
  N₁ は t の 1 次多項式で主係数 2/h、従って sup_{S₀}|N₁| ≥ 6。
- 二根 near では
    N₂(t) := n₃(x₁)(2x₂+3)+d₃(x₂)(2x₁+3)、
    Q₂(t) := d₃(x₁)d₃(x₂)。
  Π_{i=1}²ρ₃(x_i)−1 = N₂/Q₂ で、N₂ は t の 5 次多項式、主係数 4/h⁵。
  実部に複素 Chebyshev 下界を適用して sup_{S₀}|N₂| ≥ 60。

これらの下界は根配置に依存しない。c_A := 3、𝔇_SN := max(𝔇₁,𝔇₁𝔇₂) と固定する。
QR4-T で、k ≠ 0 の全因子と一根 near 場合の far 第二根をまとめた T_far に対し、
C_tail := 5 を用いて
  |T_far−1| ≤ 𝔇₁⁻¹ + C_tail h³   (一根 near)、
  |T_far−1| ≤ C_tail h³            (二根 near)
を、端点の片側差分を含む S₀ 上で証明する。同時に
|T₃| ≤ 3.1h³、|T₄| ≤ 8.6h⁴ を導く。

B₃ := 2C_tail𝔇_SN とし、
  N_A := ceil(max{12,
    (10B₃/c_A)^{1/3},
    (180𝔇_SN(5/4)⁴/c_A)^{1/4},
    (4C_tail)^{1/3}})、  h := s/N_A
と定義する。N_A は c₁・η*・ρ・個別配置に依存しない。

**SN 排除の検算式**: |e^{Δ_h³u}−1| ≤ 9η(η := 3σ_H)と上の tail 評価から、
|T_far−1| ≤ 1/2 の下で
  sup_{S₀}|N_ν| ≤ 2𝔇_SN(9η+C_tail h³)+2   (ν = 1)、
  sup_{S₀}|N_ν| ≤ 2𝔇_SN(9η+C_tail h³)     (ν = 2)
を示す。η ≤ (5s/4N_A)⁴、s ≤ 1 と N_A の定義により右辺の配置依存部分は
c_A 未満である。一根では 2+c_A < 6、二根では c_A < 60 となり、上の Chebyshev 下界と
矛盾する。P4 の完了には、この二式を exact product 恒等式から導き、far/near 境界で漏れが
ないことを示す必要がある。

**R2′ への接続(中間距離の排除)**: 上の near 条件を全 i ∈ {1,2} に適用する。
near 枝は上の矛盾で消える。補集合では各基点 t* ∈ S で、4節点が S に入る向き σ を選び、
Laurent 展開が
有効であり、v_i(t*) := h/(t*−r_i⁽⁰⁾)、
  M_i := sup_{t*∈S}|v_i(t*)|、 M_S := max_i M_i
と定義できる。P4 は QR4-I、3・4 階 tail、羃和剛性 R2′ を同じ v_i に適用し、端点を含め一様に
  M_S ≤ 4η^{1/4}+3h
を証明する。η ≤ (5s/4N_A)⁴ = (5h/4)⁴ なら M_S ≤ 8h。従って全 i について
  dist(r_i⁽⁰⁾,S) = inf_{t*∈S}|t*−r_i⁽⁰⁾| = h/M_i ≥ h/M_S ≥ 1/8。
near とその補集合は全配置を尽くすため、R_SN h < dist(r_i⁽⁰⁾,S) < 1/8 という中間領域も
R2′ の不等式で排除される。この量化と換算までを P4-contract に含める。

**zero-free tube と解析上界**: W は sup_{w∈W}dist(w,S) ≤ ℓ = 1/16 を満たす隣接窓とし、
  Ω_{S,W} := {ζ ∈ ℂ : dist(ζ,S∪W) < δ₀}、 δ₀ := 1/64
の S∪W を含む単連結成分を取る。k = 0 については
1/8−1/16−1/64 = 3/64 > δ₀、k ≠ 0 については既存の z-space gap 2.89−0.083 と
QR4-T の根換算から、全零点と Ω_{S,W} の距離が δ₀ 以上であることを P4 で証明する。
従って e^z−1 は Ω_{S,W} で零を持たない。zero-free collar だけを使う §3.8.8 の ZL を
この時点で適用して Λ_Z を得る。そこで選ぶ同じ枝 G = log(e^z−1)∘z について、
|G⁽⁶⁾| ≤ C₆κλ⁶ を絶対定数 C₆ で供給する。

### 3.8.8 WE5(P1、v0.8.3 — P2/P4 入力との合成通過)

> 固定 SHA `85bb2c2` の R-P1 R2 は本節を conditional PASS と判定した。JF-contract は
> §3.8.9/R-P2、SN-contract は §3.8.10/R-P4 R2 で証明済み。P3 の branch bootstrap を
> 閉じたとは主張しない。固定 SHA `09ca16f` の R-P1-compose が依存合成を PASS 判定した。
> 現行 state は §3.8.6 の表だけを参照する。

#### ZL: zero-free λ-bound

§3.8.7 の contract の下で、絶対定数 Λ_Z < ∞ が存在し、zero-free tube を持つ全 source 窓で
λ ≤ Λ_Z とする。

*条件付き証明*: pair-held から |z′|、|z″| は絶対有界。E → 0 または E → ∞ では
Δ_g ≍ 1 なので λ も有界。従って λ_n → ∞ となる反例列があれば E_n → 1 である。
t = t₀+τ/λ_n と拡大し、
  w_n(τ) := [z_n(t₀+τ/λ_n)−z_n(t₀)]/Δ_{g,n}
と置く。JF-2 の方向付き chart で部分列を取ると、w_n は compact τ 集合上一様に
w(τ) = Dτ+Aτ² へ収束し、max(|D|,√|A|) = 1。

ここを零点の式まで厳密化する。E_n → 1 なので、整数 k_n を一意に選んで
  ζ_n := z_n(t₀)−2πik_n = Log E_n
(1 の近傍の主枝)とできる。c_n := −ζ_n/Δ_{g,n} と置くと、部分列で
c_n → c、0 < |c| < ∞(実際 |c| → 2)。z_n は二次なので
  w_n(τ) = D_nτ+A_nτ²
は exact であり、z_n(t₀+τ/λ_n) = 2πik_n は w_n(τ) = c_n と同値である。
極限多項式 P(τ) := Dτ+Aτ²−c は非定数。A = 0 なら D ≠ 0 の一次、D = 0 なら
A ≠ 0 の二次、両方非零の場合も二次で、いずれも有界な根 τ* を持つ。τ* の周囲に
P が境界で零を持たない小円を取り、w_n−c_n → P の一様収束に Rouché を適用すると、
同円内に根 τ_n がある(重根でも同じ)。従って e^{z_n(t₀+τ_n/λ_n)}−1 = 0 で、物理 t 距離は
|τ_n|/λ_n = O(λ_n⁻¹) → 0。これは t₀ を含む P4 の複素 δ₀-collar と矛盾する。
2πik_n の選択が定数虚 gauge を吸収するため、branch の取り方にも依存しない。よって Λ_Z は有限。

#### WE5 の局所不等式

D₅ を §3.8.4 の次数 5 有限次元ノルム同値定数、C₆ を P4 の6階上界定数、c_J を P2 の
jet 床とする。安全側に
  q₀ := min{1, c_J/(4D₅C₆)}、
  ℓ* := min{1/16, q₀/(2Λ_Z)}
と置く。source S の長さ 0 < s ≤ ℓ*、隣接 W の長さ ℓ* とし、t₀ は W 側の S の端点に取る。
η* := ‖u‖_S、q := λs と書く。ZL より q ≤ λℓ* ≤ q₀/2。

- **λ = 0**: JF-0 より u は次数 ≤ 2。複素 Chebyshev から
    ‖u‖_W ≤ 18(ℓ*/s)²η* ≤ 18(ℓ*/s)⁵η*。
- **λ > 0**: JF-1 で、ある m ∈ {3,4,5} が
    |u⁽ᵐ⁾(t₀)| ≥ c_Jκλᵐ
  を満たす。§3.8.4 のノルム同値と6階剰余を S 上で使うと
    c_Jκqᵐ ≤ D₅(η*+C₆κq⁶)。
  q ≤ q₀ と m ≤ 5 より D₅C₆q^{6−m} ≤ c_J/4。右辺の剰余項を左へ移して
    κqᵐ ≤ C_Jη*、  C_J := 2D₅/c_J
  を得る。従って κq⁶ ≤ C_Jη* であり、全 0 ≤ j ≤ 5 について
    |u⁽ʲ⁾(t₀)| ≤ C_der η*s^{−j}
  (C_der := D₅(1+C₆C_J))。

Ω_{S,W} 上で t₀ まわりに5次 Taylor 展開する。多項式部は
  ‖T₅u‖_W ≤ C_pol(ℓ*/s)⁵η*。
剰余は、上で選んだ m に対し
  C₆κλ⁶ℓ*⁶
  = C₆(κqᵐ)(λℓ*)^{6−m}(ℓ*/s)ᵐ
  ≤ C₆C_Jq₀^{6−m}(ℓ*/s)⁵η*。
ここで m ≤ 5 と ℓ*/s ≥ 1 を使った。従って絶対定数
  A* := 18+C_pol+C₆C_J max(1,q₀³)
を安全側に取れば
  **‖u‖_W ≤ A*(ℓ*/s)⁵‖u‖_S**
を得る。κ を落としていないため、§3.8.6 の定数反例とは両立する。

#### 条件付き hop ledger と c₁

K を長さ ≤ ℓ* の N_W := ceil(1/ℓ*) 個の窓に分ける。u↔H 変換を含め B := 4A*、
  D_ch := 32B^{N_W+1}
と置く。I_ρ と交わる最初の窓に長さ s₀ ≥ min(ρ,ℓ*)/2 の source を取れば、従来どおり
(ℓ*/s₀)⁵ ≤ 32ρ⁻⁵。P3 の branch bootstrap が各 hop で上の WE5 を再起動できるなら
  ‖H‖_K ≤ D_ch ρ⁻⁵‖H‖_{I_ρ}。

定数の循環を避けるため、A*、D_ch、N_A の後に
  c₁ := min{
    1/(100D_ch),
    (5/(8N_A))⁴/12,
    (5ℓ*/(4N_A))⁴/(48D_ch)}
と置く。第一項は全窓で |H| < 10⁻² を保つ。ρ ≤ ℓ* では第二項が initial source の
3c₁ρ⁵ ≤ (5s₀/(4N_A))⁴ を保証し、第三項は ρ の大小によらず後続窓を保証する。
ρ ≥ ℓ* では第三項が initial source と後続窓の双方で
3D_ch c₁ ≤ (5ℓ*/(8N_A))⁴ を安全側に保証する(後続窓の長さ ℓ* に対してはさらに安全側)。
この ledger は P3 の5段帰納に条件付く。

### 3.8.9 JF の compactification 証明(P2、v0.7.9)

> 本節の proof body は固定 SHA `f36182e` の R-P2 で全 gate PASS、finding なし。
> P4 の SN/QR4-T と P3 の branch bootstrap は使用せず、それらを閉じたとは主張しない。
> 現行 state は §3.8.6 の表だけを参照する。

#### 1. exact jets

`L(z) := log(e^z−1)`、`E := e^{z(t₀)}`、`s := E−1` と書く。`E ≠ 0,1` であり、
`d := z′(t₀)`、`α := z″/2` とする。直接微分により

```
L″   = −E/s²,
L‴   =  E(E+1)/s³,
L⁗   = −E(E²+4E+1)/s⁴,
L⁽⁵⁾ =  E(E+1)(E²+10E+1)/s⁵.
```

`z‴ = 0` なので、`G := L∘z` の3–5次 jet は厳密に

```
G‴   = L‴d³ + 6L″dα,
G⁗   = L⁗d⁴ + 12L‴d²α + 12L″α²,
G⁽⁵⁾ = L⁽⁵⁾d⁵ + 20L⁗d³α + 60L‴dα².                 (JF-jet)
```

`p` は2次なので `u⁽ⁿ⁾(t₀)=G⁽ⁿ⁾(t₀)` (`n≥3`) である。

#### 2. 補助正規化と現行 scale への比較

compactification の式を見通しよくするため

```
δ₀ := min(1,|E−1|),
λ₀ := max(|d|/δ₀, sqrt(|α|/δ₀))
```

を補助的に用いる。§3.8.7 の `Δ_g` は三角不等式により

```
Δ_g = |E−1|/(1+|E|),       Δ_g ≤ δ₀ ≤ 3Δ_g.          (JF-scale)
```

実際、`|E−1|≤1` なら `|E|≤2`、`|E−1|≥1` なら
`1+|E|≤|E−1|+2≤3|E−1|` である。従って、現行の
`λ := max(|d|/Δ_g,sqrt(|α|/Δ_g))` との間に

```
λ₀ ≤ λ ≤ 3λ₀.                                             (JF-compare)
```

が成り立つ。よって補助 scale で

```
max_{3≤n≤5}|G⁽ⁿ⁾|/(κλ₀ⁿ) ≥ c₀
```

を示せば、§3.8.7 の結論は `c_J := c₀/3⁵` で従う。

以下 `(d,α)≠(0,0)` とし

```
D := d/(δ₀λ₀),   A := α/(δ₀λ₀²),
𝓝 := {(D,A)∈ℂ² : max(|D|,sqrt|A|)=1}
```

と置く。`𝓝` は compact である。`ℓ_j := L⁽ʲ⁾(z(t₀))` と書けば、(JF-jet) に代入して

```
Ψ₃ = G‴/(κλ₀³)
   = (δ₀³ℓ₃/κ)D³ + 6(δ₀²ℓ₂/κ)DA,
Ψ₄ = G⁗/(κλ₀⁴)
   = (δ₀⁴ℓ₄/κ)D⁴ + 12(δ₀³ℓ₃/κ)D²A + 12(δ₀²ℓ₂/κ)A²,
Ψ₅ = G⁽⁵⁾/(κλ₀⁵)
   = (δ₀⁵ℓ₅/κ)D⁵ + 20(δ₀⁴ℓ₄/κ)D³A + 60(δ₀³ℓ₃/κ)DA².  (JF-Ψ)
```

従って `Ψ := (Ψ₃,Ψ₄,Ψ₅)` は `E` と `(D,A)` だけの関数で、`λ₀` は消えている。

#### 3. 三つの方向付き境界

`E` 平面を Riemann 球面へ compact 化し、`0,1,∞` を極座標方向付きで blow up する。
すなわち `E=rω`、`E=1+rω`、`E=ω/r` (`r↓0`, `|ω|=1`) の三 chart と、
それらを除いた compact な中間部を貼り合わせる。これと `𝓝` の積を `𝓧` とする。
(JF-Ψ) の係数は次の極限を持つので `Ψ` は `𝓧` 上へ連続延長する。

- **`E→0`** (`ω=E/|E|`): 共通の非零因子 `−ω` を除いた境界写像は

  ```
  Ψ₃⁰ = D³+6DA,
  Ψ₄⁰ = D⁴+12D²A+12A²,
  Ψ₅⁰ = D⁵+20D³A+60DA².
  ```

  `D=0` なら `A≠0` で `Ψ₄⁰=12A²≠0`。`D≠0` かつ `Ψ₃⁰=0` なら
  `A=−D²/6` であり、`Ψ₄⁰=−(2/3)D⁴≠0`。従って共通零点はない。

- **`E→∞`** (`ω=E/|E|`): 共通の非零因子 `ω⁻¹` を除くと

  ```
  Ψ₃∞ = D³−6DA,
  Ψ₄∞ = −D⁴+12D²A−12A²,
  Ψ₅∞ = D⁵−20D³A+60DA².
  ```

  `D=0` なら第二式が非零。`D≠0` かつ第一式が0なら `A=D²/6` で、
  `Ψ₄∞=(2/3)D⁴≠0`。ここにも共通零点はない。

- **`E→1`** (`ω=(E−1)/|E−1|`): `D̂:=ω⁻¹D`、`Â:=ω⁻¹A` とし、
  全成分の共通因子4を除く。境界写像は

  ```
  Ψ̂₃¹ =  2D̂³−6D̂Â,
  Ψ̂₄¹ = −6D̂⁴+24D̂²Â−12Â²,
  Ψ̂₅¹ = 24D̂⁵−120D̂³Â+120D̂Â².
  ```

  `D̂=0` なら `Â≠0` で第二式が非零。`D̂≠0` かつ第一式が0なら
  `Â=D̂²/3` で、`Ψ̂₄¹=(2/3)D̂⁴≠0`。従って特異境界にも共通零点はない。

#### 4. 中間部の共通零点排除

`E∈ℂ∖{0,1}` が有限の内部点なら、`Ψ₃=Ψ₄=Ψ₅=0` は
`G‴=G⁗=G⁽⁵⁾=0` と同値である。`d=0` なら正規化から `α≠0` であり

```
G⁗ = −12Eα²/s² ≠ 0.
```

`d≠0` では

```
q := (E+1)d²−6αs,   R := E²−E+1,
G‴ = Edq/s³,
s⁴G⁗/E = (2Rd⁴−4(E+1)d²q−q²)/3.                         (JF-elim)
```

従って `G‴=G⁗=0` なら `q=R=0`。このとき (JF-jet) から

```
G⁽⁵⁾ = −2E(E+1)(E²+1)d⁵/(3s⁵).
```

`R=0` の二根 `E=e^{±iπ/3}` では右辺の各因子が非零なので矛盾する。よって中間部にも
共通零点はない。

#### 5. compactness と退化枝

連続関数 `max(|Ψ₃|,|Ψ₄|,|Ψ₅|)` は compact 集合 `𝓧` 上で零にならない。従って

```

### 3.8.10 SN/QR4-T と zero-free tube の証明(P4、v0.8.2)

#### 1. k=0 因子と解析 tail の厳密分離

を `𝒜(0)=0` から解析接続する。この strip には `sinh(z/2)/(z/2)` の零点がないので一価である。
Weierstrass 積から

```

```

`z` が非定数なら `z(t)=0` の根を `r_i⁽⁰⁾` (`i=1,...,ν₀`, `ν₀∈{1,2}`、重根は重複)
とする。向き `σ∈{−1,+1}`、`x_i(t):=σ(t−r_i⁽⁰⁾)/h` に対し、
`Δ^m_{σh}` を m 階前進差分と書く。`p,z/2` は3階以上の差分で消えるから

```

と置けば

```
e^{Δ³_{σh}u(t)} = [Π_i ρ₃(x_i(t))] exp τ₃(t),
e^{Δ⁴_{σh}u(t)} = [Π_i ρ₄(x_i(t))] exp τ₄(t),             (P4-product)

これは分枝に依存しない厳密恒等式である。`ν₀=1` は線形 z、`ν₀=2` は二次 z、
`d=α=0` は §3.8.9 の deg≤2 枝で処理済みである。

sup_{S₀}|N₁|≤2𝔇_SN(9η+C_tail h³)+2,

#### 4. nonnear 枝と R2′

#### 5. zero-free tube

`W` を S の隣接窓、`δ_t:=1/64` とし、

実軸上 `|Im z(t)|≤π+1/4` なので、`z(ζ)` と `2πik` の距離は

#### 6. 6階上界

上の collar だけを使う §3.8.8 ZL により `λ≤Λ_Z`。この段階では C₆ をまだ使用していないので
循環はない。`τ:=ζ−t₀` とすると Ω_{S,W} 上 `|τ|≤R_Ω:=9/64` であり、pair-held から

```

```

ここで全円板へ領域を広げず、実際の `ζ∈Ω_{S,W}` だけで denominator を比較する。
現在の gauge では k=0 方程式は `z(t)=0` である。`q₀:=z(t₀)`、`q_ζ:=z(ζ)` とし、
非退化枝の k=0 根を重複度込みで `r_i` (`1≤ν₀≤2`) と書く。(P4-push) と collar から

```

各 i について、`|t₀−r_i|≤1` なら比は 3/64 以上、`|t₀−r_i|>1` なら逆三角不等式で
比は `1−9/64=55/64` 以上である。従って

```
|q_ζ/q₀|=Π_i |(ζ−r_i)/(t₀−r_i)|≥(3/64)²=:c_r.          (P4-root-ratio)
```

`B(q):=(e^q−1)/q` (`B(0)=1`) とする。拡大 strip `|Im q|≤π+1/4+0.020` には

```

```

は q=0 で可除、`Re q→+∞` で1、`Re q→−∞` で0へ一様に近づく。従って同 strip 上
`|B′/B|≤M_B<∞`。線分積分、(P4-zmove)、(P4-root-ratio) から

```
|e^{q_ζ}−1|
=|q_ζB(q_ζ)|
≥c_r e^{−M_B B_Ω}|q₀B(q₀)|
=:c_B|e^{q₀}−1|.                                        (P4-denom)
```

また (P4-zmove) より `e^{-B_Ω}≤|e^{q_ζ}|/|e^{q₀}|≤e^{B_Ω}`。従って
`E₀:=e^{q₀}`, `E_ζ:=e^{q_ζ}` に対し

```
κ_ζ ≍ κ₀,   Δ_{g,ζ}≥c_g Δ_{g,0}                         (P4-weight)
```

が絶対定数で成り立つ。ここで `κ(E)=|E|/(1+|E|)²`、
`Δ_g(E)=|E−1|/(1+|E|)` である。

`L(q)=log(e^q−1)` の `j≥2` 階導関数は

```
L⁽ʲ⁾(q)=E P_{j−2}(E)/(E−1)^j
```

(`P_{j−2}` は固定多項式)なので

```
|L⁽ʲ⁾(q_ζ)|≤C_j κ_ζ Δ_{g,ζ}^{−j}
             ≤C′_j κ₀ Δ_{g,0}^{−j}.                     (P4-Lj)
```

一方 JF の変数 `D=d/(Δ_{g,0}λ)`, `A=α/(Δ_{g,0}λ²)` と ZL から

```
z′(t₀+τ)=Δ_{g,0}λ(D+2λAτ),
|D+2λAτ|≤1+2Λ_ZR_Ω.
```

6階 chain rule は

```

```

(P4-Lj) を各項へ代入すると、Δ_g の冪はそれぞれ正確に相殺され、λ の総次数は全て6となる。
従って λ>0 の枝で絶対定数

```
|G⁽⁶⁾(ζ)|≤C₆κ₀λ⁶       (ζ∈Ω_{S,W}).                    (P4-C6)
```

を得る。λ=0 なら `d=α=0` で z は定数、従って `G⁽⁶⁾=0` と別に定義する。
この C₆ は配置、S、W、ρ、c₁ に依存せず、Ω 外の点を compactness 集合へ加えていない。
