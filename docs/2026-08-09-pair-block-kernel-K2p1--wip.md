## 1. 設定と主張

F = B₁₂ + c₃e^{q₃}、B₁₂(t) := c₁e^{q₁(t)} + c₂e^{q₂(t)}(c_j ≠ 0、q_j 相異なる複素 2 次)、
pair held: β_B := sup_K|η| ≤ 1/8(η := q₂ − q₁)。K 長さ 1、E ⊆ K 長さ ρ。
**木包絡**: U_T(t) := max(log|B₁₂(t)|, m₃(t))、m₃ := log|c₃| + Re q₃。
(U_T > −∞ 各点: B₁₂ の零点でも m₃ は有限。)

**予想 K(2)+1(v0.1)**: ‖e^{−U_T}F‖_{∞,K} ≤ C_T ρ⁻⁴ ‖e^{−U_T}F‖_{∞,E}(C_T 絶対定数)。

設計性質(いずれも定義から直ちに):
- **天井**: e^{−U_T}|F| ≤ 2 が **exact** に成立(|F| ≤ |B₁₂| + e^{m₃} ≤ 2e^{U_T})。
- **phantom の根治**: pair が深く相殺すれば log|B₁₂| がそのまま下がる — 包絡が虚偽に
  膨れない。§3.6.0 反例の摂動族(q₂ = q₁ + 1/10 + δt²、c₁ = −c₂e^{1/10})は
  δ = 10⁻¹〜10⁻⁸ で一様に比 ≈ 2·10⁻⁴·ρ⁻⁴(数値、§4)— U_F では 1/δ 発散だった。
- W = 3 帳簿の保存(pair は質量 2 の block のまま、Taylor 剰余を独立 weight に数えない)。

## 2. 補題 F2(pair block の厳密因数分解)【証明済み】

**補題 F2**: 上の設定で w を e^{w} = −c₁/c₂ かつ |Im(w − η(t_c))| ≤ π なる分枝
(t_c = E 中心)、z(t) := η(t) − w、E(z) := (e^z − 1)/z(E(0) = 1)とすると
  **Φ := c₁ + c₂e^{η} = c₂e^{w} · (η(t) − w) · E(z(t))**(恒等式)
であり、ν := Re w = log|c₁/c₂| による三分岐で次が成立:

- **(D1) ν ≤ −2(原子 2 支配)**: Re z ≥ 15/8 で
  Φ = c₂e^{η}·V₂、V₂ := 1 − e^{−z}、|V₂| ∈ [1 − e^{−15/8}, 1 + e^{−15/8}] ⊂ [0.84, 1.16]。
  B₁₂e^{−q₂} 側で読む: **deg 0 多項式 c₂ × 単位 V₂ × e^{q₂}**。
- **(D2) ν ≥ 2(原子 1 支配)**: Re z ≤ −15/8 で Φ = c₁·V₁、V₁ := 1 − e^{z}、
  |V₁| ∈ [0.84, 1.16]。**deg 0 多項式 c₁ × 単位 V₁ × e^{q₁}**。
- **(D3) |ν| < 2(相殺可能域)**: z(K) ⊆ B* := [−17/8, 17/8] × i[−(π+1/4), π+1/4]。
  E は B* 上零点なし(E の零点は 2πik、|2πk| ≥ 2π > π + 1/4)で
  **|E| ∈ [0.27, 3.5]、‖(log E)^{(j)}‖_{∞,B*} ≤ (0.8, 0.17, 0.09)(j = 1,2,3)**
  (数値評価、グリッド 401×601 — 解析的裏付け: |E| ≥ (1−e^{−17/8})/|z| ≥ 0.88/4.01、
  |E| ≤ (e^{17/8}−1)/(17/8) ≤ 3.5)。
  **P_Φ(t) := c₂e^{w}(η(t) − w) は真正な deg ≤ 2 多項式で、その零点 = Φ の零点**
  (η(t) = w の解、K 上高々 2 個)。Φ = P_Φ · V、V := E(z(t))。

*証明*: 恒等式は c₁ = −c₂e^{w} の代入(数値 5 配置 ≤ 6·10⁻¹⁶)。分枝の存在: η(K) は
半径 β_B ≤ 1/8 の円板内、Im w は 2π 刻みで選べるので |Im(w−η(t_c))| ≤ π にできる。
Im z の評価: |Im z| ≤ |Im(η − η(t_c))| + π ≤ 2β_B + π ≤ π + 1/4。
(D1): Re z = Re η − ν ≥ −1/8 + 2 − 1/8… 正しくは ≥ −β_B + 2 ≥ 15/8、
|e^{−z}| ≤ e^{−15/8} ≤ 0.154、Φ = c₂e^{η}(1 − e^{−z}) は恒等式の書換え。(D2) 対称。
(D3): |Re z| ≤ |ν| + β_B < 17/8 と Im 評価で z(K) ⊆ B*。E の非零性は零点の位置から。∎

**帰結(包絡の等価)**: 各分岐で U_T = max(log|P·V| + Re q_b, m₃)(q_b = 基準位相、
P = 該当多項式)は、単位の有界性より
  **U″ := max(log|P| + Re q_b, m₃) との差が一様有界**: |U_T − U″| ≤ max(|log 0.27|, log 3.5) ≤ 1.31
(D3; D1/D2 は ≤ 0.18)。bridge 損失 e^{2·1.31} ≤ 14 — **discount は絶対定数**
((iii) 型の非有界 Δ* はここでは発生しない — P_Φ が真の零点を持つため)。

## 3. 証明経路(v0.2 で改訂 — 抽象化 K2QV の反証と構造化路線)

### 3.1 抽象化 K2QV は偽(Sol 監査 2026-08-09 — 本線検算済み)

v0.1 の目標「F = PVe^{q_b} + c₃e^{q₃}、V 零点なし・‖log V‖_{C³} ≤ Λ_V で
C(Λ_V)ρ⁻⁴ kernel」は**偽**。
**反例(検算済み、k2qv_refute_check.py)**: g := (1/10)(t−1/2)₊⁴(C³、E = [0,1/2] 上 ≡ 0)、
V := e^{−t²/100+g}、P = −1、q_b = (i+1/100)t²、q₃ = it²。‖log V‖_{C³} < 2 だが
PVe^{q_b} = −e^{g+it²} で **E 上完全相殺**: e^{−U_V}|F| = 1−e^{−g} は E 上 0、K 上 > 0 —
有限な C(Λ_V) は存在しない。**解析的 V でも C³ 有界だけでは不足**
(V_N = e^{−t²/100+t^N/N³}: 比 ≥ 2^{N−1}、数値確認 N = 8/16/24 で 256/6.6·10⁴/1.7·10⁷)。
教訓: C³-tame 抽象化は E 局在の平坦こぶを許す — 必要なのは**有限次元性**であって滑らかさでない。
定量帰結(Sol、検算受諾): SN 分岐の下界 4.1·10⁻³⁹ に対し C³ 摂動 Λ_Vh³ ~ 10⁻³ は 36 桁大きく、
R2′ 連鎖にも η 非依存項が残って絶対距離への押し出しが死ぬ — 定数調整では根治不可能。

### 3.2 移植が成立する部分(Sol 検証 + 本線受諾)

- **場合 (a)(b)**: G := e^{−U_V}|F| ≤ 2 の天井と max 包絡構造のみで
  ‖G‖_K ≤ 3.2‖G‖_E / 55‖G‖_E — 単位の帳簿すら不要(**成立**)。
- **場合 (c1)(c2)(平坦性継承)・(c-ii)**: pointwise 不等式のみ — **成立**
  ((c-ii): ‖G‖_K ≤ 2.3·10⁴⁰ρ⁻⁴‖G‖_E)。
- **T1 sharp test**: V = 1 を含む限りそのまま入り、ρ⁻⁴ は必要(**成立**)。
- **限定 D1/D2**: log V が複素 2 次多項式なら位相に吸収して K2(300ρ⁻⁴)— **成立**。
  ただし実際の単位 1−e^{±z} はこの限定に入らない。
- **障害は (c-i)(深平坦 × 外挿・剛性)に完全に局在**。

### 3.3 改訂された証明経路: F2 構造を最後まで保持する

一般単位への抽象化を破棄し、F2 の相関構造 **PV = a(e^{z(t)} − 1)**(z = η − w 複素 2 次、
osc_K z ≤ 1/4)を仮定に保持する。残る核心は次の**有限次元族の剛性・外挿補題**:

**補題 QR4(目標)**: u(t) = log(e^{z(t)} − 1) + p(t) + C(z, p 複素 2 次、osc_K z ≤ 1/4、
枝は連続選択)の族に対する、K2Q 場合 (c-i) 相当の四次剛性
(J 上深平坦 σ_H < c₁ε⁴ ⇒ 「e^z − 1 の零点データ」が遠方 or SN 矛盾)。
V = E(z) を誤差扱いせず、恒等式を最後まで使う。パラメータは z の係数 3 + p の係数 3 −
正規化で実質有限次元 — C³ 反例の「自由な平坦こぶ」は構成不可能(z の 2 次性が邪魔をする)、
これが成立根拠の直観。Sol 自信度 0.65(路線として)。

方針候補(次工程で選定):
- (i) K2Q の有限差分を z-変数に取り直す: Δ³[log(e^z−1)] を z の 2 次性で展開 —
  「z の零点データ」= η(t) = w の解(K 上 ≤ 2 個)に対する ρ₃ 型恒等式 +
  log E(z) 項の**構造化**摂動(任意 C³ でなく E∘(2 次) — 消せない主要項を特定する)。
- (ii) compactness + 一意接続: 族が実質 6 パラメータ・正規化後 compact であることを使い、
  「深平坦 ⇒ 退化」の定量版を Łojasiewicz 型で出す(定数の明示性が犠牲 — 閉包側の
  絶対定数要求と要整合)。
- (iii) 三原子恒等式の直接探索: c = 3 専用の e^{Δᵏ} 型厳密恒等式(K2Q の §5.2 の類似)が
  pair-block 形に存在するか — Sol の過去判定は「単一 log 正規形なし」だが、
  それは gauge e^{−q₁}F への判定で、**(e^z−1) 因子化後の形には未判定**。
