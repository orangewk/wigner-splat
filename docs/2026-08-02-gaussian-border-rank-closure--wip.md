## 0. 主結果サマリ

**主定理(閉包定理)**: 単一モード。rank ≤ k のガウス重ね合わせ状態の集合 G_k の L² 閉包の任意の元は、Bargmann 表示で有限指数多項式
  F = Σ_c P_c(z)·exp(½A_c z² + B_c z)、(A_c,B_c) 相異・|A_c| < 1、
の形を持ち、クラスタ重み r_c(≥ 1, Σ_c r_c ≤ k)により deg P_c ≤ 2(r_c − 1)。

**系 C1**: 閉包の元は全て実解析的波動関数 ⇒ 半直線台の非零状態 ψ は全 k で閉包外 ⇒ **K_ε^G(ψ) → ∞ (ε→0)**。
**系 C2**: κ^G_border(|2t⟩) ≤ t+1(偶 Fock の半減)。κ^G(|2⟩) = 2 確定。
**系 C3**: κ^G(ψ) < ∞ ⟺ ψ が上記指数多項式型 — C–C Thm 8 のガウス辞書版(質的)。

## 1. 設定・記法

- ℱ = Bargmann–Fock 空間、⟨f,g⟩ = ∫ f ḡ e^{−|z|²} dA/π。再生核評価 |f(z)| ≤ ‖f‖e^{|z|²/2}。
- 原子写像 Φ(ξ) := e^{½Az²+Bz}、ξ = (A,B) ∈ Ω := {|A|<1}×ℂ。γ(定数項)は係数に吸収。
- ノルム公式: **‖Φ(A,B)‖² = (1−|A|²)^{−1/2} exp[(|B|² + Re(A B̄²))/(1−|A|²)]**
  (検算: A=0 → e^{|B|²} ✓ コヒーレント、B=0 → (1−|A|²)^{−1/2} ✓ squeezed vacuum)。
- Φ は Ω 上 ℱ 値正則(局所有界 + 弱正則)。
- K = K_{δ,R} := {|A| ≤ 1−δ} × {|B| ≤ R}(コンパクト)。
- G_k := 単位球 ∩ {Σ_{j≤k} c_j Φ(ξ_j)}。ψ_m → ψ (L²) with ψ_m ∈ G_k ⟺ K_ε^G(ψ) ≤ k ∀ε。

**用語**: 導来原子 = P(z)Φ(ξ)(P 多項式)。パラメタ列の**クラスタ**: 相互距離 → 0 の原子群。**クラスタ木**: 反証部分列上で距離比・方向を安定化して得る階層(§5.1)。

## 2. 補題 L0(既存資産、引用)

**L0(指数多項式独立性)**: s_i 相異(差が非定数)・P_i ≢ 0 なら Σ P_i e^{s_i} ≢ 0。
出典 = #135 comment 5150322136(独立査読済み)。古典帰属 = Heittokangas et al. arXiv:2202.01574 §3。
帰結: 相異パラメタの導来原子有限系は ℱ で線形独立(次数の異なる同一原子上の多項式因子も込み)。

## 3. 補題 L1(弱脱出)

**L1**: 正規化原子 Φ̂(ξ_m) は |A_m| → 1 または |B_m| → ∞ のとき 0 に弱収束。
さらに固定プロファイル g に対し D(β_m)g(|β_m| → ∞)⇀ 0。

*証明*: 稠密系 {|n⟩} でテスト。⟨n|Φ(A,B)⟩ = √(n!)·Σ_{2s+t=n}(A/2)^s B^t/(s!t!) は (A,B) の多項式。
(i) |A| → 1, |B| ≤ R: 分子有界、‖Φ‖ ≥ (1−|A|²)^{−1/2}e^{−C(δ',R)} → ∞ … 正確には exp 部の下界
  (|B|²+Re(AB̄²) ≥ |B|²−|B|² = 0 とは限らないが ≥ −2|B|² ≥ −2R² で一様下界)⇒ ‖Φ‖ ≳ (1−|A|²)^{−1/4}·e^{−2R²/(1−|A|²)}…
  [注意: exp 部は負になり得るが (1−|A|²)^{−1/2} 因子が発散、exp 部下界 e^{−2R²/(1−|A|²)} と競合 —
  **要清書**: 正しくは正規化重なりの直接評価 |⟨n|Φ̂⟩|² ≤ (多項式)·(1−|A|²)^{1/2}e^{+2R²/(1−|A|²)}…が発散しては駄目。
  → 清書時は既知の squeezed-coherent 状態の Fock 係数漸近(|⟨n|S(r)D(α)|0⟩| → 0 as r → ∞ 一様 n 固定)を引くのが安全。
  物理的には自明(無限スクイーズは任意の固定 Fock 成分を失う)だが定数確認を査読項目に残す]
(ii) |B| → ∞: |⟨n|Φ̂⟩| ≤ poly(|B|)·e^{−c(δ)|B|²} → 0(‖Φ‖ の exp 下界が |B|² オーダーで効く)✓。
(iii) D(β)g ⇀ 0: 標準(位相空間平行移動の弱消滅)。∎(清書 1 点残し)

## 4. 補題 L2a(一様増大度評価)— 本定理の技術的核心

**L2a**: ∃C = C(k,δ,R): 任意の f = Σ_{j≤k} c_j Φ(ξ_j)(ξ_j ∈ K 相異)について
  |f(z)| ≤ C·(1+|z|)^{2(k−1)}·e^{(1−δ)|z|²/2 + R|z|}·‖f‖  (∀z ∈ ℂ)。

### 4.1 証明の構造(反証部分列 + クラスタ木 + 再帰 Newton 枠)

反証: 配置列 𝒞_m ⊂ K と単位ベクトル f_m ∈ span 𝒞_m、点 z_m で重み付き超過 → ∞ と仮定。
部分列抽出で安定化: 各ペア距離 d_{ij}^{(m)} は「≥ d̄ > 0 に留まる」か「→ 0」に二分し、
微小距離同士の比は [0,∞] 内で収束、方向も収束。⇒ **クラスタ木 T**: 葉 = 原子、内部節点 ν = クラスタ、
節点スケール s_ν^{(m)}(→ 0)、子スケール/親スケール → 0 または定数比。

**再帰 Newton 枠**: 節点 ν の枠 = 子枠の合併を、節点スケールの divided difference で
Gram–Schmidt 順(スケール昇順)に非退化化したもの。書き換えは常に三角・係数増大は高々 ×(節点子数)
(c₁Φ₁ + c₂Φ₂ = (c₁+c₂)Φ₁ + c₂(Φ₂−Φ₁) 型)。各差分操作は多項式次数を ≤ +2 上げ、
原子点数を 1 減らす。総差分回数 ≤ k−1 ⇒ **多項式次数 ≤ 2(k−1)** ✓。

### 4.2 正規化 Newton 元の二領域評価(一般階、機構検証済み)

節点スケールで再スケールした t パラメタ(間隔比 ≥ c に安定化済み)上の o 階 divided difference:
  g(t) := Φ(ξ + t η̂)(z) = e^{q(z) + t η̂(z)}、[t_0…t_o]g を考える。ノルム下界 ‖[t_0…t_o]Φ‖ ≥ c|η̂|^o
  (極限 = p_η̂^o e^q/o!·(間隔積) ≠ 0、K×S³ コンパクト性 — p_η̂(z) = ½η̂_A z² + η̂_B z ≢ 0)。
- **微分領域** |η̂(z)| ≤ 1: 剰余公式で |[·]g| ≤ C|η̂(z)|^o max_t|e^{q+tη̂(z)}| ≤ C(|η̂|(1+|z|)²)^o e^{(1−δ)|z|²/2+R|z|+1}。
- **脱結領域** |η̂(z)| ≥ 1: Lagrange 形 [·]g = Σ_i g(t_i)/Π(t_i−t_j)、間隔 ≥ c で
  |[·]g| ≤ C max_i|g(t_i)| ≤ C e^{(1−δ)|z|²/2+R|z|}(全原子 ∈ K)。
  正規化後 ≤ (C/|η̂|^o)e^{…}、かつ 1 ≤ |η̂(z)| ≤ C|η̂|(1+|z|)² ⇒ 1/|η̂|^o ≤ C(1+|z|)^{2o}。
**両領域とも (1+|z|)^{2o} e^{(1−δ)|z|²/2+R|z|} が η̂ に一様**。接合点 |z|² ~ 1/|η̂| で両評価が一致(検算済み: o = 1, 2 明示計算 §9)。

**多重スケール(節点の入れ子)**: 節点 ν の差分は「子枠要素」に作用する。再スケール極限で子クラスタは
その中心の導来原子系に凍結(子の内部スケール ≪ s_ν)。混合項(節点微分が子の多項式因子に当たる項)は
節点スケールで低次 → 剰余に吸収。帰納法はクラスタ木の深さ + 各節点の子数について回る。
[**査読重点箇所**: この凍結・吸収の一様性の形式化。機構は §9 の検証計算と同型]

### 4.3 Gram 一様可逆性と結論

正規化枠要素は部分列上で導来原子系に norm 収束(§5)。極限系は相異原子×相異次数 ⇒ L0 で線形独立
⇒ 極限 Gram 可逆 ⇒ 十分先で Gram 最小固有値 ≥ c > 0。よって f_m = Σ a_i û_i の係数は |a| ≤ C‖f_m‖。
各 û_i は 4.2 の一様評価を満たす ⇒ |f_m(z)| ≤ C(1+|z|)^{2(k−1)}e^{(1−δ)|z|²/2+R|z|}‖f_m‖ — 反証仮定と矛盾。∎

## 5. 補題 L2b(極限空間の分類)

**L2b**: コンパクトパラメタ(⊂ K)の k 原子スパン列 V_m は部分列上で dim k の極限空間 V を持ち、
V = 導来原子系 {P_i Φ(ξ'_i)} の張る空間(クラスタ c ごとに r_c 個・deg ≤ 2(r_c−1)、Σ r_c = k)。
枠は ℱ-norm 収束する。

*証明*: 4.1 の枠要素は u.o.c. 収束(パラメタ収束 + 正則性)。L2a の一様評価 ⇒ 一様可積分尾部
(|û|²e^{−|z|²} ≤ poly·e^{−δ|z|²+2R|z|})⇒ **u.o.c. + 一様尾部 = norm 収束**。極限は構成により
導来原子の三角結合。独立性(L0)で dim 保存。∎

## 6. 補題 L3(クラスタ間の一様分離、プロファイル分解)

**L3**: 反証部分列上の安定化クラスタ分割(コンパクト群 𝒦、脱出群 ℰ)について、
クラスタ和 h_c への分解は Σ_c ‖h_c‖² ≤ C‖Σ_c h_c‖² を満たす(joint Gram 一様可逆)。

*証明骨格*: 脱出型を分類:
(E1) |A| → 1: 任意の固定状態・他クラスタ正規化原子との重なり → 0(重なり公式
  |⟨Φ̂₁,Φ̂₂⟩| = [(1−|A₁|²)(1−|A₂|²)]^{1/4}/|1−Ā₁A₂|^{1/2}·e^{(B-項)} の直接評価)⇒ 漸近直交。
(E2) A コンパクト・|B| → ∞: クラスタ中心 β_m で D(β_m)† を作用(ユニタリ不変)⇒ プロファイル
  k_c(コンパクトパラメタ系)に還元。異クラスタ: B 中心差 → ∞ なら変位分離で重なり → 0;
  中心共有なら A プロファイル相異 → L0 独立。
仮に joint 退化(単位結合 Σh_c → 0, max‖h_c‖ = 1)なら: コンパクト群は L2b で norm 収束、
極限系は相異原子 ⇒ L0 独立 ⇒ コンパクト極限 = 0; 残る脱出群はプロファイル還元後
同様に独立 ⇒ 全 h_c → 0、max‖h_c‖ = 1 と矛盾。∎
[査読箇所: E1/E2 混在クラスタ(|A|→1 かつ |B|→∞)の場合分けの網羅性]

## 7. 主定理の証明(端末議論 — v1.0 で簡約)

ψ_m ∈ G_k、ψ_m → ψ(L² 強)。部分列でクラスタ構造を安定化、F_m = F_m^𝒦 + F_m^ℰ。
1. L3 ⇒ 各クラスタ和ノルム一様有界。
2. L2b ⇒ F_m^𝒦 は(部分列上)**強収束**: F_m^𝒦 → g ∈ V = 導来原子スパン、総重み ≤ k。
3. すると F_m^ℰ = F_m − F_m^𝒦 も**強収束**(強収束列の差)、極限 = ψ − g。
4. 一方 F_m^ℰ ⇀ 0(L1 + プロファイル構造 + 有界係数)。強収束 + 弱極限 0 ⇒ ψ − g = 0。
∴ ψ = g ∈ V: 指数多項式状態、クラスタ重み公式付き。∎
(旧 v0.1 の三角評価・質量保存の議論は不要になった — 強収束の差で閉じる)

**系 C1**: V の元の波動関数 = Σ P̃_c(x)e^{ガウス}(Bargmann 逆変換、有限和)= 実解析的。
半直線台の非零 ψ は開区間 x < 0 で消えるが ≢ 0 ⇒ 実解析的でない ⇒ ψ ∉ 閉包(G_k) ∀k
⇒ K_ε^G(ψ) は ε→0 で非有界。∎

## 8. 系 C2・C3(副産物)

**C2**: κ^G(|2t⟩) ≤ t+1: ε ↦ e^{εz²} は ℱ 値正則(|ε| < ½)⇒ (t+1) 点 divided difference →
(d/dε)^t e^{εz²}|₀ = z^{2t}(norm 収束、Banach 値 Cauchy 積分公式)。coherent 辞書の 2t+1(C–C)から半減。
下界 t+1 は主定理の重み公式から: z^{2t} = P e^{0}、deg P = 2t ≤ 2(r−1) ⇒ r ≥ t+1 ✓ **一致、確定**。
奇 |2t+1⟩: 下界 = 重み公式 + 表現一意性(L0)から deg 2t+1 ≤ 2(r−1) ⇒ **r ≥ t+2(確定、閉包定理条件付き)**。
上界 = ∂_A^t∂_B 矩形スキームで **2t+2**(粗い)。曲線スキームの試行(B = cε^t 等)は全てパリティで
z^{2t+2} が混入し t+2 点では z^{2t+1} に到達しない — Waring border rank(x^t y の border rank = t+1、
Landsberg–Teitler)との対応が示唆的だが変換は未確立。**真値 ∈ [t+2, 2t+2]、開**(G4)。
**注意(査読点)**: 重み公式の「実現可能な P の空間」は deg ≤ 2(r_c−1) の必要条件までが本稿の主張。
どの P が実現するか(到達可能空間の完全決定)は未解決 — C2 奇の真値はこれに依存。

**C3**: κ^G(ψ) < ∞ ⟺ Bargmann F が指数多項式(重み有限)。C–C open problem の質的解決。
定量版(κ^G_ε の ε-rate、structured Hankel 下界)は次フェーズ。

## 9. 検証済み明示計算(付録)

1. **z² / 2 原子(o=1 接合検算)**: ‖(e^{εz²}−1)/ε − z²‖ ≤ Σ_{t≥2}ε^{t−1}√((2t)!)/t! ≤ Σ ε^{t−1}O(2^t) → 0 ✓
2. **z⁴ / 3 原子(o=2)**: 3 点 divided difference of e^{εz²} → z⁴/2、‖e^{εz²}‖² = (1−4|ε|²)^{−1/2} 有限域で
   Banach 正則 ⇒ norm 収束 ✓。二領域接合: |Δ²Φ(z)| = |e^{q}||e^{η}−1|²、|η(z)| ≶ 1 で patch、
   境界 |z|² ~ 1/|η| で両評価一致 ✓
3. **z³ / 4 原子**: 4 点矩形スキーム (0,0),(h,0),(0,h'),(h,h') の二重差分 → ∂_A∂_B Φ = z³·(½)e^0 + 低次 ✓
4. **κ^G(|2⟩) = 2 の下界**: G_1 閉包 = {c Φ(ξ)} ∪ {0}(1 原子は零点自由 + Hurwitz)、z² は零点あり ✓
5. **半直線 canonical 状態**: F(z) = αe^{−z²/2} + βz(1+erf(z/√2))(手計算 2 回検算)— 指数多項式でない
   (erf 因子、L0 と両立しない増大・零点構造)⇒ C1 の適用例 ✓
