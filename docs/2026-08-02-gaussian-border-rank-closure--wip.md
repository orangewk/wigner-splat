## 0. 主結果サマリ

**主定理(閉包定理)**: 単一モード。rank ≤ k のガウス重ね合わせ状態の集合 G_k の L² 閉包の任意の元は、Bargmann 表示で有限指数多項式
  F = Σ_c P_c(z)·exp(½A_c z² + B_c z)、(A_c,B_c) 相異・|A_c| < 1、
の形を持ち、クラスタ重み r_c(≥ 1, Σ_c r_c ≤ k)により deg P_c ≤ 2(r_c − 1)。

**系 C1**: 閉包の元は全て実解析的波動関数 ⇒ 半直線台の非零状態 ψ は全 k で閉包外 ⇒ **K_ε^G(ψ) → ∞ (ε→0)**。
**系 C2**: κ^G_border(|2t⟩) = t+1(偶 Fock の半減、閉包定理条件付き)。κ^G(|2⟩) = 2 確定。奇は [t+2, 2t+2] 開。
**系 C3**: κ^G(ψ) < ∞ ⟺ ψ が上記指数多項式型 — C–C Thm 8 のガウス辞書版(質的)。

## 1. 設定・記法

- ℱ = Bargmann–Fock 空間、⟨f,g⟩ = ∫ f ḡ e^{−|z|²} dA/π。再生核評価 |f(z)| ≤ ‖f‖e^{|z|²/2}。
- 原子写像 Φ(ξ) := e^{½Az²+Bz}、ξ = (A,B) ∈ Ω := {|A|<1}×ℂ。γ(定数項)は係数に吸収。
- ノルム公式: ‖Φ(A,B)‖² = (1−|A|²)^{−1/2} exp[(|B|² + Re(A B̄²))/(1−|A|²)]。
  **指数部の下界(査読提供、検算済み)**: Re(AB̄²) ≥ −|A||B|² より
  **|B|² + Re(AB̄²) ≥ (1−|A|)|B|² ≥ 0**、ゆえに ‖Φ(A,B)‖ ≥ (1−|A|²)^{−1/4}·e^{|B|²/(2(1+|A|))·0}
  … 正確には exp 部 ≥ e^{(1−|A|)|B|²/(2(1−|A|²))} = e^{|B|²/(2(1+|A|))} ≥ e^{|B|²/4}。
- Φ は Ω 上 ℱ 値正則。K = K_{δ,R} := {|A| ≤ 1−δ} × {|B| ≤ R}(コンパクト)。
- 正規化原子 Φ̂(ξ) := Φ(ξ)/‖Φ(ξ)‖。E(z) := e^{(1−δ)|z|²/2+R|z|}(K 上の envelope)。

### 1.5 共変構造(v1.1 新設)

**群 G** := 単一モード affine metaplectic 群(squeeze S(ζ)・displacement D(β)・位相で生成)。
標準事実(検算方針は §9.1):
- (i) **共変性**: U ∈ G は正規化原子を正規化原子に移す: U Φ̂(ξ) = (位相)·Φ̂(U·ξ)。
  パラメタ作用: D(β) は A 固定で B を affine 平行移動、S(ζ) は A 円板に SU(1,1) Möbius 作用 + B に線形作用。
- (ii) **推移性**: G は Ω に推移的に作用する(任意の ξ を (0,0)(真空)に移せる)。
- (iii) **不変計量**: d_Ω := (A 円板の双曲距離) × (gauge 済み B 距離) の G 不変距離。
以後「配置の gauge」とは、配置の指定原子(基準原子)を (0,0) へ移す U ∈ G の適用をいう。

**重なり公式(拡張 L1 の基礎)**: 推移性より一般の重なりは基準原子を真空に gauge して
  |⟨Φ̂(ξ₁), Φ̂(ξ₂)⟩| = |⟨0|Φ̂(ξ′)⟩| = ‖Φ(ξ′)‖^{−1} ≤ (1−|A′|²)^{1/4}·e^{−|B′|²/4}
(ξ′ = 相対パラメタ、最後の不等式は上の指数部下界)。**右辺 → 0 ⟺ d_Ω(ξ₁,ξ₂) → ∞** ✓。

## 2. 補題 L0(既存資産、引用)

**L0(指数多項式独立性)**: s_i 相異(差が非定数)・P_i ≢ 0 なら Σ P_i e^{s_i} ≢ 0。
出典 = #135 comment 5150322136(独立査読済み)。古典帰属 = Heittokangas et al. arXiv:2202.01574 §3。
帰結: 相異パラメタの導来原子有限系は ℱ で線形独立。

## 3. 補題 L1(拡張版: 重なり減衰と弱消滅)

**L1-a(重なり減衰)**: |⟨Φ̂(ξ₁), Φ̂(ξ₂)⟩| ≤ (1−|A′|²)^{1/4} e^{−|B′|²/4} → 0(d_Ω(ξ₁,ξ₂) → ∞)。
*証明*: §1.5 の重なり公式そのもの。旧 v1.0 の L1(i) の符号ギャップは査読提供の不等式で閉鎖。∎

**L1-b(弱消滅)**: U_m ∈ G、U_m → ∞(コンパクト集合を離れる)なら、任意の固定 g ∈ ℱ に対し U_m g ⇀ 0。
*証明*: g, テストベクトル h を原子の有限結合で近似(原子系は total: コヒーレント稠密性の標準拡張)。
|⟨h, U_m g⟩| ≤ Σ(係数)|⟨Φ̂(ξ_i), Φ̂(U_m ξ_j)⟩| + 2ε‖·‖: U_m → ∞ ⇒ d_Ω(ξ_i, U_m ξ_j) → ∞ ⇒ L1-a で第 1 項 → 0。
ユニタリ性で近似誤差は一様。∎

## 4. 補題 L2a(一様増大度評価)— 技術的核心

**L2a**: ∃C = C(k,δ,R): 任意の f = Σ_{j≤k} c_j Φ(ξ_j)(ξ_j ∈ K 相異)について
  |f(z)| ≤ C·(1+|z|)^{2(k−1)}·E(z)·‖f‖  (∀z ∈ ℂ)。

### 4.1 証明の構造

反証部分列 + 安定化(ペア距離の二分・距離比・方向の収束)→ クラスタ木 T。以後、補題 N(§4.3)を
最小スケール優先の帰納で適用し、一様 Gram 可逆な正規化枠を得る。枠係数は ‖f‖ で抑えられ、
枠要素は §4.2–4.3 の envelope を満たすから L2a が従う。

### 4.2 単一スケール二領域評価(v1.0 §4.2 を「一般化原子」に拡張)

**一般化原子**: 三つ組 (ξ, o, u) — 基点 ξ ∈ K、次数 o ≥ 0、正規化関数 u ∈ ℱ で
  (E-o) |u(z)| ≤ C_o(1+|z|)^{2o}E(z)、
  (X) u は原子 ≤ (o+1) 個の exact 結合(係数明示)、
  (L-o) u は部分列上で P·Φ(ξ*)(P ≢ 0, deg P ≤ 2o)へ norm 収束、
を満たすもの。重み w := o+1。素の正規化原子は (ξ, 0, Φ̂(ξ))。

**単一スケール divided difference 評価**: 基点間隔が単一スケール s(間隔比 ≥ c に安定化済み)の
一般化原子列に対する o′ 階 divided difference は、二領域貼り合わせ
- 微分領域 |η̂(z)| ≤ 1: 剰余公式 + (E-o) ⇒ (1+|z|)^{2o+2o′} 因子
- 脱結領域 |η̂(z)| ≥ 1: Lagrange 形 + 間隔下界 + ノルム下界(L0 + コンパクト性)⇒ 1/|η̂|^{o′} ≤ C(1+|z|)^{2o′}
により (E-(o+o′)) を満たす(計算は v1.0 §4.2 と同一機構、多項式因子が乗法的に運ばれる)。

### 4.3 補題 N(階層 Newton 枠 — v1.2: 主張 + 部分的構成、一般証明は G1′ = open)

**補題 N(主張)**: {(ξ_i, o_i, u_i)}_{i≤c} を相異基点の一般化原子系、総重み w = Σ(o_i+1)、基点の相互距離が
単一スケール s_m → 0(比安定化済み)とする。このとき部分列上で、span{u_i} の正規化枠 {v_1..v_w′}(w′ = dim)
であって次を満たすものが exact 代数(原子の有限結合)で構成できる:
  (N1) 各 v_l は一般化原子 (ξ*, o_l′, v_l)、o_l′ ≤ w − 1、Σ(o_l′+1) ≤ w;
  (N2) {v_l} の Gram は一様可逆(下界は極限系の L0 独立性 + コンパクト性);
  (N3′) 各 v_l は原子の exact 有限結合で、**結合係数は m とともに発散してよい** — 要求は評価の側にのみ置く:
    envelope (E-o_l′) が m 非依存定数で成立すること。
  (N4) envelope 定数 C は (c, {o_i}, δ, R, 安定化定数) のみに依存(m 非依存)。

**(N3) の撤回(v1.2)**: 旧 (N3)「基底変換係数は m 一様有界」は再査読の反例により**偽**:
c=2 のコヒーレントペア Φ̂(0), Φ̂(s)(s→0)で Gram 最小固有値は Θ(s²) であり、一様 Gram 化には
Θ(1/s) の変換係数が必須(クレジット: 再査読 2026-08-02)。同反例の v₂ = (u₂−u₁)/‖u₂−u₁‖ 自体は
(N2)+(N3′)+(E-1) を満たす(Gram → 単位行列・二領域評価、検算済み)— つまり誤っていたのは
「係数有界」という言明であり、置くべき要求は関数レベルの envelope だった。

**アーキテクチャの (N3) 非依存性(v1.2 総点検)**: §4.4(f の枠係数 ≤ C‖f‖)は (N2) のみ、
§6(ブロック Gram)は (N2) + ユニタリ不変性のみ、§7 step 1/3 は (N2)+(L-o)+L1-b のみを使う。
u→v 変換係数の有界性はどの段でも使われていない。

### 4.3.1 モーメント濾過による構成(v1.3 — 補題 N 証明本体、単一スケール完全版)

**構造的事実(μ 引き戻しの次数付き単射性)**: 原子の指数は線形 ⟨ξ, μ(z)⟩、**μ(z) := (½z², z)**
(モーメント曲線/放物線)。斉次 n 次多項式 q ∈ Sym^n(ℂ²)* の引き戻し q(μ(z)) は、単項式
y₁^a y₂^b(a+b = n)を z^{2a+b} に写し、次数 2a+b = n+a が a ごとに相異なるから、
**Sym^n ≅ span{z^n, …, z^{2n}} の線形同型**。∎(3 行、v1.3 検証計算 §9.8)
⇒ 衝突配置の解析は ℂ² の点配置のモーメント代数に**無損失で還元**される(放物線の特殊性)。

**モーメント濾過**: 配置 τ_j := ξ_j − ξ*(j ≤ c、相異、|τ| ~ s → 0)。p_j(z) := ⟨τ_j, μ(z)⟩。
係数ベクトル c ∈ ℂ^c に対し h_c := Σ_j c_j e^{p_j}·Φ(ξ*) の位数 ord(c) := min{n : M_n(c) ≠ 0}、
M_n(c) := Σ_j c_j τ_j^{⊗n} ∈ Sym^n(ℂ²)(次数付き単射性より「z 多項式として」と同値)。

**正則性上界**: c ≠ 0 ⇒ **ord(c) ≤ c−1**。
*証明*: ord ≥ c なら Σ_j c_j q(τ_j) = 0 が全ての deg ≤ c−1 多項式 q で成立。だが Lagrange 積
q_i = Π_{j≠i} ℓ_j(ℓ_j = τ_j で消え τ_i で消えない一次式、deg ≤ c−1)が c_i = 0 を強いる。∎

**枠の構成(次数付き基底 + 適応的補正、m ごとの実配置上で実行)**:
1. 各 m で旗 F_n := {c : M_k(c) = 0, k < n} を取る(F_c = 0 は正則性上界)。旗は有限次元
   Grassmannian に住むので部分列で収束 — 次数プロファイル d_n = dim(F_n/F_{n+1}) を安定化。
   次数付き基底 {c^{(l)}} は**有界**(旗収束から)。
2. 候補 v_l = h_{c^{(l)}}/‖·‖。極限: h/s^{n_l} → (1/n_l!)·q_l(μ(z))Φ(ξ*)(norm 収束 — 尾部は
   Σ_k (2Cs)^k の幾何級数で優界、§9.9)。q_l ≠ 0(次数付き単射性)。
3. **適応的補正(退化幾何の処理)**: 極限 q_l(μ) が既採用元の極限の張る空間に入る場合
   (異なる次数の z-範囲 [n, 2n] は重なるため起こりうる — 例: y₁ と y₂² は共に z² を与える)、
   既採用元の適切なスケール倍を厳密減算して ord を厳増させ、拾い直す。減算後も係数ベクトルは
   非零(三角性)なので正則性上界 ord ≤ c−1 が発動し**有限終端**、終端時の極限は既採用空間の外
   ⇒ 極限系は線形独立 ⇒ **(N2) 一様 Gram 可逆**(コンパクト性)。
   — 旧「素朴 divided difference の極限消滅」問題はここで解消: 消滅・退化(共線化等)は単に
   d_n プロファイルの変化であり、構成が自動的に追随する。
4. **envelope(N3′/N4)**: 二領域。
   - Taylor 領域(全 |p_j(z)| ≤ 1): |h(z)| ≤ C max|c_j|·max_j|p_j(z)|^{ord} ≤ C′ s^{ord}(1+|z|)^{2·ord}E(z)
     (係数有界性は手順 1)。‖h‖ ≥ c·s^{ord}(手順 2 の極限非零 + コンパクト性)⇒ (E-ord) ✓。
   - 脱結領域(ある |p_j(z)| ≥ 1): 項数勘定 + 床 (1+|z|)² ≥ 1/s(§9.6 の機構)⇒ 同 envelope ✓。
   補正(手順 3)は既採用元の有界スケール倍の減算なので envelope を保つ。∎(単一スケール)

**単一スケールの補題 N: 以上で証明完了**(残る点検は routine: §9.8–9.9 の計算と手順 4 脱結領域の清書)。

### 4.3.2 多重スケール再帰(jet 版 — G1′ の残余)

クラスタ木の節点では「原子」が子クラスタの枠要素(多項式因子付き)になる。対応する双対は
**多重度付き点配置(jet)のモーメント濾過**: 評価汎関数が τ_i での高階微分込みになる。
- 正則性上界の jet 版: 総重み w の jet 配置で ord ≤ w−1(Lagrange 積 Π ℓ_j^{m_j}、同型の議論)。
- 構成手順 1–4 は同型に走る(係数有界性は節点ごとの旗安定化、envelope はスケール床の帰納 —
  §9.6 の 3 領域が 2 スケールの検証例)。
**状態**: 構成スキームと鍵補題(jet 正則性・スケール床帰納)は明示済みだが、**完全な帰納の執筆は
未了 = G1′ の残余**。単一スケール(§4.3.1)は完結、G1′ は「jet 版の清書 + スケール帰納の形式化」に縮小。
補題 N 全体が閉じるまで、L2a・L2b・主定理・系 C1 は**条件付き**(v1.2 と同じ扱い)。

### 4.4 Gram 一様可逆性と L2a の結論

補題 N の反復適用で得た枠は (N2) より一様 Gram 可逆 ⇒ f_m の枠係数 ≤ C‖f_m‖ ⇒ (E-o) 束ねて
|f_m(z)| ≤ C(1+|z|)^{2(k−1)}E(z)‖f_m‖ — 反証仮定と矛盾。∎

## 5. 補題 L2b(極限空間の分類)

**L2b**: コンパクトパラメタ(⊂ K)の k 原子スパン列 V_m は部分列上で dim k の極限空間 V を持ち、
V = 導来原子系 {P_i Φ(ξ'_i)} の張る空間(クラスタ c ごとに r_c 個・deg ≤ 2(r_c−1)、Σ r_c = k)。
枠は ℱ-norm 収束する。

*証明*: 補題 N の枠は u.o.c. 収束(パラメタ収束 + 正則性)+ L2a の一様 envelope ⇒ 一様可積分尾部

## 6. 補題 L3(gauge 化クラスタ分離、v1.1 で再構成 — blocking 2 対応)

**クラスタの再定義**: 原子列 {ξ_j^{(m)}} を「**相対 gauge の有界性**」で同値類別する:
j ~ j′ ⟺ d_Ω(ξ_j^{(m)}, ξ_{j′}^{(m)}) が m 一様有界。同値類 = クラスタ。部分列で類別を安定化。
各クラスタ c に gauge U_m^{(c)} ∈ G(基準原子 → 真空)を取ると、gauge 後の配置は
コンパクト集合 K_c ⊂ Ω に入る(有界相対距離 + 部分列)。**旧「脱出クラスタ」は存在しない** —
全クラスタがコンパクト配置 + gauge 列 の形になる(旧 G3 の E1/E2 混在もここで解消)。

**L3**: クラスタ和分解 F_m = Σ_c U_m^{(c)} k_m^{(c)}(k_m^{(c)} = コンパクト配置の原子結合)について
  Σ_c ‖k_m^{(c)}‖² ≤ C‖F_m‖²(joint Gram 一様可逆)。

*証明*: 各クラスタ内で補題 N の枠(gauge 後、コンパクト ⇒ 適用可)を取り U_m^{(c)} で戻すと、
F_m の全体枠 = ⋃_c {U_m^{(c)} v_{c,l}}。ブロック内 Gram = 一様可逆((N2)、ユニタリ不変)。
ブロック間 Gram: ⟨U^{(c)}v_{c,l}, U^{(c′)}v_{c′,l′}⟩ = ⟨v_{c,l}, (U^{(c)})^{-1}U^{(c′)} v_{c′,l′}⟩、
相対 gauge (U^{(c)})^{-1}U^{(c′)} → ∞(クラスタ相異の定義)+ v は norm 収束(L2b)⇒ **L1-b で → 0**。
ゆえに全体 Gram → ブロック対角 + o(1)、一様可逆。∎

## 7. 主定理の証明(端末議論)

ψ_m ∈ G_k、ψ_m → ψ(L² 強、位相整列後)。部分列でクラスタ構造(§6)を安定化。
