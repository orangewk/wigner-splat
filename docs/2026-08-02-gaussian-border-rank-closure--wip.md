## 1. 設定・記法

- ℱ = Bargmann–Fock 空間、⟨f,g⟩ = ∫ f ḡ e^{−|z|²} dA/π。再生核評価 |f(z)| ≤ ‖f‖e^{|z|²/2}。
- 原子写像 Φ(ξ) := e^{½Az²+Bz}、ξ = (A,B) ∈ Ω := {|A|<1}×ℂ。γ(定数項)は係数に吸収。
- ノルム公式: ‖Φ(A,B)‖² = (1−|A|²)^{−1/2} exp[(|B|² + Re(A B̄²))/(1−|A|²)]。
  **指数部の下界(査読提供、検算済み)**: Re(AB̄²) ≥ −|A||B|² より
  **|B|² + Re(AB̄²) ≥ (1−|A|)|B|² ≥ 0**、ゆえに exp 部 ≥ e^{(1−|A|)|B|²/(2(1−|A|²))} = e^{|B|²/(2(1+|A|))}
  ≥ e^{|B|²/4}、すなわち ‖Φ(A,B)‖ ≥ (1−|A|²)^{−1/4}·e^{|B|²/4}。
- Φ は Ω 上 ℱ 値正則。K = K_{δ,R} := {|A| ≤ 1−δ} × {|B| ≤ R}(コンパクト)。
- 正規化原子 Φ̂(ξ) := Φ(ξ)/‖Φ(ξ)‖。E(z) := e^{(1−δ)|z|²/2+R|z|}(K 上の envelope)。

### 1.5 共変構造(v1.1 新設)

**群 G** := 単一モード affine metaplectic 群(squeeze S(ζ)・displacement D(β)・位相で生成)。
標準事実(検算方針は §9.1):
- (i) **共変性**: U ∈ G は正規化原子を正規化原子に移す: U Φ̂(ξ) = (位相)·Φ̂(U·ξ)。
  パラメタ作用: D(β) は A 固定で B を affine 平行移動、S(ζ) は A 円板に SU(1,1) Möbius 作用 + B に線形作用。
- (ii) **推移性**: G は Ω に推移的に作用する(任意の ξ を (0,0)(真空)に移せる)。
- (iii) **不変計量**: d_Ω := (A 円板の双曲距離) × (gauge 済み B 距離) の G 不変距離。
以後「配置の gauge」とは、配置の指定原子(基準原子)を (0,0) へ移す U ∈ G の適用をいう。

**重なり公式(拡張 L1 の基礎)**: 推移性より一般の重なりは基準原子を真空に gauge して

**class 正規化 |q_j″| ≤ 2 を仮定**(応用では |q_j″| = |A_j| ≤ 1−δ で満たされる。qwen レビュー

K2(c=2)自体は正規化なしでも成立 — 証明が係数の大きさを使わないため))。
- 振幅包絡: m_j(t) := log|c_j| + Re q_j(t)(**実** 2 次多項式)、V(t) := max_j m_j(t)。
- I = 長さ 1 の閉区間、J ⊆ I 閉・長さ ε ∈ (0,1]、Λ := max_j sup_I |q_j'|、A := sup_I V − sup_J V(≥ 0)。
- 自明上界: |F(t)| ≤ Σ_j e^{m_j(t)} ≤ c·e^{V(t)}(pointwise)。

**補題 K2(c = 2 kernel — 無条件)**: c = 2 のとき
  sup_I |F| ≤ 300 ε^{−2} e^{A + Λε} · sup_J |F|。
周波数 Λ は指数に **Λε のみ**(chaining では ε ∝ δ と取り吸収)、底 300/ε² は周波数非依存。

*証明*. F ≡ 0 は自明。H := F/(c₁e^{q₁}) = 1 + w e^{p}、w = c₂/c₁、p = q₂ − q₁ とおく。
φ := log|w| + Re p = m₂ − m₁、ψ := arg w + Im p(いずれも**実 2 次多項式**; arg w は一つ固定)。
|H| = |1 + e^{φ+iψ}| について初等不等式:
 (P1) |H| ≤ 1 + e^{φ} ≤ 2e^{max(0,φ)}、すなわち |F| ≤ 2e^{V}(pointwise)。
 (P2) |H| ≥ |e^{φ} − 1|。 (P3) |H| ≥ e^{φ}|sin ψ|。
 (P4) cos ψ ≥ 0 なら |H|² = 1 + 2e^{φ}cos ψ + e^{2φ} ≥ 1。
記号: σ := sup_J|F|、σ_H := sup_J|H|、t₂ := argmax_J|H|(σ ≥ |F(t₂)| = e^{m₁(t₂)}σ_H)。
実 2 次式の osc_J g ≤ ε·sup_I|g′| を osc_J m_j ≤ Λε の形で繰り返し使う(|m_j′| = |Re q_j′| ≤ Λ)。

*場合 (a): sup_J φ ≥ 1*。t_a := argmax_J φ。(P2) より
|F(t_a)| ≥ e^{m₁(t_a)}(e^{φ(t_a)}−1) ≥ (1−e^{−1}) e^{m₂(t_a)}。t₃ := argmax_J V とすると:
V(t₃) = m₂(t₃) なら m₂(t_a) ≥ m₂(t₃) − Λε。V(t₃) = m₁(t₃) なら: φ(t₃) ≥ −1 のとき
m₂(t₃) ≥ m₁(t₃) − 1 で同様、φ(t₃) < −1 のとき (P2) で |F(t₃)| ≥ (1−e^{−1})e^{m₁(t₃)} が直接出る。

sup_I|F| ≤ 2e^{sup_I V} = 2e^{A}e^{sup_J V} ≤ 9 e^{A+Λε} σ。∎(a)

*場合 (b): sup_J φ ≤ 1 かつ σ_H ≥ 1/10*。J 上 pointwise V ≤ m₁ + 1 より
sup_J V ≤ sup_J m₁ + 1 ≤ m₁(t₂) + Λε + 1、σ ≥ e^{m₁(t₂)}/10 ≥ (1/10)e^{sup_J V − 1 − Λε}。
(P1): sup_I|F| ≤ 2e^{A}e^{sup_J V} ≤ 55 e^{A+Λε} σ。∎(b)

*場合 (c): sup_J φ ≤ 1 かつ σ_H < 1/10*。J 上 pointwise |H| ≤ σ_H から**平坦性データ**が出る:
 (c1) (P2) ⇒ |e^{φ}−1| ≤ σ_H ⇒ |φ| ≤ 1.2σ_H。特に e^{φ} ≥ 0.88。
 (c2) (P4) ⇒ cos ψ < 0(さもなくば |H| ≥ 1 > σ_H)。(P3) ⇒ |sin ψ| ≤ σ_H/0.88 ≤ 1.14σ_H
  ⇒ dist(ψ, (2ℤ+1)π) ≤ (π/2)·1.14σ_H ≤ 1.8σ_H。ψ は J 上連続で、奇数倍 π の集合(間隔 2π)から

 (c3) **Chebyshev 外挿**(補題 E、古典): 実多項式 g(deg ≤ 2)が長さ ε の J 上 |g| ≤ μ なら、
  J を含む長さ 1 の I 上 |g| ≤ 18μ/ε²(affine で J → [−1,1] とすると I は |x| ≤ 3/ε に入り

 u := φ + i(ψ−(2k₀+1)π) とおくと I 上 H = 1 − e^{u}、|u| ≤ B := 55σ_H/ε²。

  (上と同じ)より sup_I|F| ≤ 2e^{A}e^{sup_J V} ≤ 2e^{0.12}·55 ε^{−2} e^{A+Λε} σ ≤ 125 ε^{−2} e^{A+Λε} σ。∎(c)

3 場合の最大は (c-i) の 170(ε ≤ 1 で 9, 55, 125 もすべて ≤ 300/ε²)— C₀ = 300 として主張が従う。∎

  (rate degeneration が表面化 — class を quasipolynomial 𝒬_k に拡張し重み k で帰納)。
  L2a 自体は純指数和にしか適用しないが、帰納の閉性のため kernel は 𝒬_k で立てるのが頑健。

### 4.3.5 一般 c への攻略 v1.8 — peeling / 位相 block 分解 / compact core(設計 + 部分証明)

§4.3.4 末尾の攻略候補を具体化した 3 段アーキテクチャ。**v1.3 型 compactness の失敗(周波数方向が
非コンパクトなまま極限を取った)を、「compactness を使う前に周波数を量子化する」ことで回避する**
のが設計思想。K_c の主張は gauge 不変なので、以後 gauge で sup_J V = 0 と正規化する
(共通因子 e^{g} の乗算。純虚 g = −iθ_ref による共通位相の除去も同様に合法 — |e^{iθ_ref}| = 1 で
V 不変)。σ := sup_J|F|。

**skeleton**:
1. **B1(振幅 peeling)**: dead 項(J 上で包絡から K 以上劣位)を相対摂動として吸収して c を減らす
   (帰納)か、全項 live・振幅データ有界の正規形へ(J は ≤ 4^c 倍まで縮めてよい —
   K_c は J を部分区間に置き換えると強くなるだけ)。
2. **浅い相殺(σ ≥ σ₀ e^{sup_J V})**: 自明上界 |F| ≤ ce^{V} で直接
   sup_I|F| ≤ ce^{A}e^{sup_J V} ≤ (c/σ₀)e^{A}σ ✓ 終了。
3. **深い相殺(σ < σ₀ e^{sup_J V})**: 位相勾配 θ_j′(t) = Im(q_j′)(1 次式、傾き |Im a_j| ≤ 2)を
   J 上 M₀-gap でクラスタし block 分解 F = Σ_b G_b e^{iθ_b}:
   - **≥ 2 blocks(B2)**: 深い相殺は**起き得ない**(σ ≥ σ₁(c,ε,K,M₀) > 0 の下界)⇒ σ₀ := σ₁ と
     取れば本 case は空 ⇒ 矛盾で閉じる。
   - **1 block(B3)**: 相対位相の 2 次式係数が有界 ⇒ 全パラメタがコンパクト集合 P に入る ⇒
     部分解析的 curve selection で比汎関数の有界性。

**K_c の定式化訂正(v1.8.1、qwen レビュー反映)**: kernel は「自己選択部分区間」形で立てる:
  **K_c: ∃ J′ ⊆ J(|J′| ≥ ε/C₁(c)(1+Λε))で sup_I|F| ≤ C(c,ε) e^{A(J′)+κ(c)Λε} sup_{J′}|F|**、
A(J′) := sup_I V − sup_{J′} V。chaining への影響なし(C′ が使うのは A(J′) ≤ Lip(V)·diam(I) ≤ Λ_k
のみで、これは J′ がどこでも成立。sup_{J′}|F| ≤ sup_{J_k}|F| ≤ sup_{I_{k+1}}|F| も不変)。
また **poly(1+Λε) 因子は e^{κΛε} に吸収可能**((C(1+Λε))^γ ≤ C′e^{γΛε})なので、
J′ の長さ・底定数の Λ-依存はこの形まで許される — 「底は周波数非依存」の要件はこの意味で読む。

**補題 B1(peeling — v1.8.1 改訂: 一段構成)**: K = K(c,ε) 定数。D_j := sup_J V − sup_J m_j。
(i) *dead 吸収*: D_j ≥ K なる j は L = {j: D_j < K} に対する相対摂動として吸収:
J 上 |F_dead| ≤ ce^{−K}e^{sup_JV}。σ ≥ 2ce^{−K}e^{sup_JV} なら σ_L ≤ (3/2)σ、A_L ≤ A + K、
sup_I|F_dead| ≤ ce^{A+K}σ で K_{|L|} に帰着 ✓。σ < 2ce^{−K}e^{sup_JV} なら深い相殺 case へ。
(ii) *piece 選択(v1.8.3 再改訂 — Codex blocking 1 対応: 閾値を **V-アンカー**に変更)*: まず J を
長さ ε′ = ε/(C₁(1+Λε)) の等分片(半開区間の規約 — 境界点の帰属を一意化、Codex 指摘 5)に分け、
V の sup を最大化する片 J₀ を取る(sup_{J₀}V ≥ sup_JV − osc ≥ sup_JV − (O(1)+O(Λε))・
osc_{J₀}m_j ≤ Λε′ ≤ O(1)+O(Λε) — 一様 O(ε) とはならない点を訂正(Codex 指摘))。
J₀ 上で各項の **V-アンカー閾値集合 {t: m_j(t) ≥ sup_{J₀}V − 2K}**(旧稿の per-term アンカー
sup_{J₀}m_j は誤り — 「自身比では高いが V 比で低い」項が有界確定に紛れ、値窓 Mε → ∞ の反例が
立つ(Codex 反例: m₁ = −Mt, m₂ = M(t−ε))— 撤回)の境界点(2 次式 vs 定数レベルで ≤ 2 点/項、
計 ≤ 2c 点)を考え、J₀ の 4c 等分(半開)のうち内部に境界点を含まない片(≥ 2c 個)から
sup V 最大の片 J′ を取る。J′ 上で全項が V-閾値に対し同時に片側的:
高側 ⇒ m_j ∈ [sup_{J₀}V − 2K − O(1+Λε′), sup_{J₀}V] — **V 基準の値窓で有界確定** ✓。
低側 ⇒ sup_{J′}m_j ≤ sup_{J₀}V − 2K ≤ sup_{J′}V − 2K + (V-drop) ⇒ D_j(J′) ≥ K(V-drop ≤ K の
パラメタ選択)⇒ dead、(i) で吸収。一段で終了。損失は e^{O(K)}·e^{O(1)+O(Λε)} — 仕様の
C(c,ε)e^{κΛε} 内。終状態: J′ 上全項 live・**V 基準値窓 ≤ C(K)+O(Λε′)**・相対振幅 u_j の係数は
J′-スケールで有界(共通部分 m_{j*} の大勾配は残る — compact core には入れず補題 As で処理)。∎
(dead/live 閾値と σ₀ の依存順は DAG: Q(c) → M₀ 窓(M* ≥ 16)→ K(c,ε) → σ₀ = min(σ₁, ce^{−K})。)

**補題 B2(block 非相殺 — open、設計)**: 正規形(B1 後)で block 数 ≥ 2 なら

#### 4.3.6.1 補題 N-P1(Gram 連続性 + 極限独立性供給 — accepted、R-NP1 R2 PASS `c893f04`)

**補題 N-P1(i)(Gram 連続性)**: `r ∈ {1,2,3}`(有限なら一般の `r` でも同文)。
`v_{1,m}, …, v_{r,m} ∈ ℱ` が各 `ℓ` で `v_{ℓ,m} → v_ℓ^*`(ℱ-norm)を満たし、極限系
`{v_1^*, …, v_r^*}` が線形独立なら、`λ_* := λ_min(Gram(v_1^*,…,v_r^*)) > 0` であり、
ある `m₁` が存在して全 `m ≥ m₁` で

  λ_min(Gram(v_{1,m},…,v_{r,m})) ≥ λ_*/2 > 0.

下界 `λ_*/2` は部分列の極限配置に依存する(それで (N2)_{c≤3} には十分 — 量化 target 参照)。

*証明*: (1) norm 収束列は有界: `S := sup_{ℓ,m}‖v_{ℓ,m}‖ < ∞`。内積の連続性
(`|⟨v_{i,m},v_{j,m}⟩−⟨v_i^*,v_j^*⟩| ≤ ‖v_{i,m}−v_i^*‖·S + ‖v_i^*‖·‖v_{j,m}−v_j^*‖`)より
Gram 行列は成分ごとに収束し、`r × r`(`r ≤ 3` 有限)なので作用素 norm でも収束:
`‖G_m − G_*‖ → 0`。(2) `{v_ℓ^*}` 線形独立 ⇒ `G_*` は正定値 ⇒ `λ_* > 0`。(3) Hermite 行列の
固有値摂動(Weyl)`|λ_min(G_m) − λ_min(G_*)| ≤ ‖G_m − G_*‖` より、`‖G_m − G_*‖ ≤ λ_*/2` と
なる `m₁` 以降で `λ_min(G_m) ≥ λ_*/2`。∎

**補題 N-P1(ii)(極限独立性の供給規約)**: 有限系 `{P_i Φ(ξ^*_{g(i)})}_{i≤r}`(`P_i ≢ 0` 多項式、
基点 `ξ^*_g` は group `g` ごとに相異、`g(i)` = i の属する group)について、**各 group 内で

##### 4.4.1.1 補題 NC-1(L2a′(c=3) — accepted、R-NC1 R3 PASS `b003341`)

表示係数 `c_j` は statement にも証明にも定量的に現れない(norm 経由でのみ制御)。

*証明*(反証部分列): 成立しないとすると、`C = m`(`m ∈ ℕ`、単調性より ℕ 上の反証で十分)

を得る(`C_w^N, C_lin^N` は §4.3.6.5 定数総括の max — `(δ,R,ε_chain,C_T,C_RF)` のみに依存し、
**部分列に依存しない**)。以下部分列の `m ≥ m₀` に制限する(反証は無限個の m で成立して
いるから制限可能)。`f_m` は(quotient 後の)残存原子の結合なので `f_m ∈ V_m`。
