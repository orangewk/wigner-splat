## 1. 設定

F(t) = Σ_{j=1}^{c} c_j e^{q_j(t)}(t 実変数、c_j ∈ ℂ∖{0}、q_j 相異なる複素 2 次多項式)。
- 振幅包絡: m_j(t) := log|c_j| + Re q_j(t)(**実** 2 次多項式)、V(t) := max_j m_j(t)。
- I = 長さ 1 の閉区間、J ⊆ I 閉・長さ ε ∈ (0,1]、Λ := max_j sup_I |q_j'|、A := sup_I V − sup_J V(≥ 0)。
- 自明上界: |F(t)| ≤ Σ_j e^{m_j(t)} ≤ c·e^{V(t)}(pointwise)。
- 注意: A は定数モジュラス gauge(位相 e^{iθ(t)}・定数実因子)で不変。非定数実 gauge では変わる —
  実 gauge の処理は証明中の pointwise assembly が担う。
- 本定理(c = 2)は |q_j''| の大きさを一切使わない(class 正規化不要)。

## 2. 主結果

**定理 K2(2 次位相・2 項の区間型 Turán 不等式)**: c = 2 のとき
  **sup_I |F| ≤ 300 ε^{−2} e^{A + Λε} · sup_J |F|**。
周波数 Λ は指数に Λε としてのみ入り、底 300/ε² は周波数非依存。ε^{−2} は sharp(数値確認:
Chebyshev 退化配置で真の比 ≈ 8/ε² を達成 — 最良定数は ≈ 8、300 は安全余裕)。

**補題 E(Chebyshev 外挿、古典)**: 実多項式 g(deg ≤ 2)が長さ ε の区間 J 上 |g| ≤ μ なら、
J を含む長さ 1 の区間 I 上 |g| ≤ 18μ/ε²。
*証明*: affine で J → [−1,1] とすると I は |x| ≤ 3/ε に入り、Chebyshev の極値性から
|x| ≤ 1 では |g| ≤ μ。1 ≤ |x| ≤ 3/ε では
|g(x)| ≤ μ|T₂(|x|)| ≤ 2μx² ≤ 18μ/ε²。ε ≤ 1 より前者も同じ上界に入る。∎

### 定理 K2 の証明

F ≡ 0 は自明。H := F/(c₁e^{q₁}) = 1 + w e^{p}、w = c₂/c₁、p = q₂ − q₁ とおく。
φ := log|w| + Re p = m₂ − m₁、ψ := arg w + Im p(いずれも実 2 次多項式; arg w は一つ固定)。
|H| = |1 + e^{φ+iψ}| について初等不等式:
 (P1) |H| ≤ 1 + e^{φ} ≤ 2e^{max(0,φ)}、すなわち |F| ≤ 2e^{V}(pointwise)。
 (P2) |H| ≥ |e^{φ} − 1|。 (P3) |H| ≥ e^{φ}|sin ψ|。
 (P4) cos ψ ≥ 0 なら |H|² = 1 + 2e^{φ}cos ψ + e^{2φ} ≥ 1。
記号: σ := sup_J|F|、σ_H := sup_J|H|、t₂ := argmax_J|H|(σ ≥ |F(t₂)| = e^{m₁(t₂)}σ_H)。
実 2 次式の osc_J g ≤ ε·sup_I|g′| を osc_J m_j ≤ Λε の形で繰り返し使う(|m_j′| = |Re q_j′| ≤ Λ)。

*場合 (a): sup_J φ ≥ 1*。t_a := argmax_J φ。(P2) より
|F(t_a)| ≥ e^{m₁(t_a)}(e^{φ(t_a)}−1) ≥ (1−e^{−1}) e^{m₂(t_a)}。t₃ := argmax_J V とすると:
V(t₃) = m₂(t₃) なら m₂(t_a) ≥ m₂(t₃) − Λε。V(t₃) = m₁(t₃) なら: φ(t₃) ≥ −1 のとき
m₂(t₃) ≥ m₁(t₃) − 1 で同様、φ(t₃) < −1 のとき (P2) で |F(t₃)| ≥ (1−e^{−1})e^{m₁(t₃)} が直接出る。
いずれも σ ≥ 0.23·e^{−Λε} e^{sup_J V}。(P1) より
sup_I|F| ≤ 2e^{sup_I V} = 2e^{A}e^{sup_J V} ≤ 9 e^{A+Λε} σ。∎(a)

*場合 (b): sup_J φ ≤ 1 かつ σ_H ≥ 1/10*。J 上 pointwise V ≤ m₁ + 1 より
sup_J V ≤ sup_J m₁ + 1 ≤ m₁(t₂) + Λε + 1、σ ≥ e^{m₁(t₂)}/10 ≥ (1/10)e^{sup_J V − 1 − Λε}。
(P1): sup_I|F| ≤ 2e^{A}e^{sup_J V} ≤ 55 e^{A+Λε} σ。∎(b)

*場合 (c): sup_J φ ≤ 1 かつ σ_H < 1/10*。J 上 pointwise |H| ≤ σ_H から平坦性データが出る:
 (c1) (P2) ⇒ |e^{φ}−1| ≤ σ_H ⇒ |φ| ≤ 1.2σ_H。特に e^{φ} ≥ 0.88。
 (c2) (P4) ⇒ cos ψ < 0(さもなくば |H| ≥ 1 > σ_H)。(P3) ⇒ |sin ψ| ≤ σ_H/0.88 ≤ 1.14σ_H
  ⇒ dist(ψ, (2ℤ+1)π) ≤ (π/2)·1.14σ_H ≤ 1.8σ_H。ψ は J 上連続で、奇数倍 π の集合(間隔 2π)から
  1.8σ_H < 1 以内に留まる ⇒ 分枝 k₀ は J 上一定: |ψ − (2k₀+1)π| ≤ 1.8σ_H on J。
 (c3) 補題 E を φ と ψ−(2k₀+1)π(いずれも実 2 次)に適用:
  sup_I|φ| ≤ 22σ_H/ε²、sup_I|ψ−(2k₀+1)π| ≤ 33σ_H/ε²。
 u := φ + i(ψ−(2k₀+1)π) とおくと I 上 H = 1 − e^{u}、|u| ≤ B := 55σ_H/ε²。
 (c-i) B ≤ 1: sup_I|H| ≤ sup_I|u|e^{|u|} ≤ eB ≤ 150σ_H/ε²。t₁ := argmax_I|F| で
  sup_I|F| = e^{m₁(t₁)}|H(t₁)| ≤ 150ε^{−2} e^{m₁(t₁)−m₁(t₂)} |F(t₂)|。指数の評価:
  m₁(t₁) ≤ V(t₁) ≤ sup_I V。J 上 V ≤ m₁ + max(0,φ) ≤ m₁ + 1.2σ_H より
  sup_J V ≤ sup_J m₁ + 0.12 ≤ m₁(t₂) + Λε + 0.12 ⇒ m₁(t₁)−m₁(t₂) ≤ A + Λε + 0.12。
  ⇒ sup_I|F| ≤ 170 ε^{−2} e^{A+Λε} σ。
 (c-ii) B > 1(σ_H > ε²/55): e^{m₁(t₂)} = |F(t₂)|/σ_H ≤ 55σ/ε²。sup_J V ≤ m₁(t₂)+Λε+0.12
  (上と同じ)より sup_I|F| ≤ 2e^{A}e^{sup_J V} ≤ 2e^{0.12}·55 ε^{−2} e^{A+Λε} σ ≤ 125 ε^{−2} e^{A+Λε} σ。∎(c)

3 場合の最大は (c-i) の 170(ε ≤ 1 で 9, 55, 125 もすべて ≤ 300/ε²)— C₀ = 300 として定理が従う。∎

### 検証(反例群との整合)

- **chirp**(H = 1 + e^{iat²}): 場合 (c) は |ψ−(2k₀+1)π| ≤ 1.8σ_H on J を要求するため
  σ_H ≥ osc_J ψ / 3.6 — 位相が J 上で動くほど持続的相殺は不可能になり、証明は周波数を底に
  持ち込まずに閉じる(ψ の停留点が J 内にあると osc_J ψ ≈ |ψ″|ε²/4 まで落ちるので「σ_H ≳ Λε」
  とまでは言えない)。零点数 Θ(aρ²) は本証明のどこにも現れない(零点勘定不使用)。
- **rate degeneration**(w → −1, p → 0, H → 0 恒等): 場合 (c) が一様に適用され、σ_H → 0 でも
  比は 300/ε² のまま — rate-agnostic。
- **単独支配**(第 2 項が無視可能): 場合 (a)/(b) で e^{A} 係数 1 — 包絡の真の減衰と整合。
本証明は実 2 次多項式の外挿のみを使い、複素解析(零点数・Jensen・Harnack)を一切使わない。

## 3. 応用: Fock 空間の一様増大度(radial chaining)

設定(Bargmann–Fock): 原子 Φ(ξ) = e^{½Az²+Bz}、K_{δ,R} = {|A| ≤ 1−δ}×{|B| ≤ R}、
再生核評価 |f(z)| ≤ ‖f‖e^{|z|²/2}。

**補題 C′(radial chaining — c 一様)**: 「kernel(c): K2 型不等式(底 C(c,ε)ε^{−γ(c)}、指数
e^{A+κ(c)Λε})」を仮定する。f = Σ_{j≤c} c_jΦ(ξ_j)、‖f‖ = 1(斉次性で一般化可)、
(A_j,B_j) ∈ K_{δ,R}。z₀ = Te^{iθ}(T ≥ T₀ = 3。|z| < T₀ は再生核評価で自明)に対し
g(s) := f(se^{iθ}) = Σ c_j e^{q_j(s)}、q_j(s) = ½(A_je^{2iθ})s² + (B_je^{iθ})s は §1 の class に
入り |q_j″| ≤ 1−δ、|q_j′(s)| ≤ (1−δ)s + R。
**ε := min(1/2, δ/(8(κ(c)+1)))** と固定。区間列
I_k = [a_k, a_k+1]、a_1 = T−1、a_{k+1} = a_k − (1−ε)、a_N ≤ 1 で停止(N ≤ 2T+1)。
J_k := I_k ∩ I_{k+1}(長さ ε)。kernel(c) を各 (I_k, J_k) に適用(Λ_k := (1−δ)(a_k+1)+R、
A_k ≤ Lip_{I_k}(V)·diam(I_k) ≤ Λ_k — V は Lipschitz 定数 ≤ max_j sup|m_j′| ≤ Λ_k の max):
 |f(z₀)| ≤ sup_{I_1}|g| ≤ Π_{k<N} [C(c,ε)ε^{−γ} e^{A_k+κΛ_kε}] · sup_{I_N}|g|。
指数の積算: Σ_k(A_k + κΛ_kε) ≤ (1+κε)Σ_kΛ_k
≤ (1+κε)(1−ε)^{−1}[(1−δ)(T+1)²/2 + C_R(T+1)]。
この ε では κε ≤ δ/8 かつ ε ≤ δ/8 なので
  (1−δ)(1+κε)/(1−ε) ≤ (1−δ)(1+δ/8)/(1−δ/8) ≤ 1−δ/2。
したがって上式は ≤ (1−δ/2)T²/2 + C(δ,R)T。
底の積算: (Cε^{−γ})^{N} = e^{C(c,δ)T}。終端: sup_{I_N}|g| ≤ sup_{[0,2]}|g| ≤ e²‖f‖。
 ⇒ **|f(z₀)| ≤ e^{(1−δ/2)T²/2 + C(c,δ,R)T}‖f‖**。∎

**系(L2a′、c = 2、他の open 補題に非依存)**: active rank-2、すなわち
`c₁c₂≠0`, `ξ₁≠ξ₂` の 2 原子重ね合わせ
f = c₁Φ(ξ₁) + c₂Φ(ξ₂)(ξ_j ∈ K_{δ,R})に対し、K2 は kernel(2)(γ = 2、κ = 1)を与えるので
  **|f(z)| ≤ e^{(1−δ/2)|z|²/2 + C(δ,R)|z|}·‖f‖  (∀z ∈ ℂ)**。
`c_j=0` または `ξ₁=ξ₂` の場合は、zero-pruningまたは係数のexact併合を先に行う。係数和が0なら
`f=0`。それ以外はrank-1であり、`Φ(A,B)(0)=1` から `‖Φ(A,B)‖≥1`、また
`|Φ(A,B)(z)|≤exp((1−δ)|z|²/2+R|z|)` なので、同じ弱形が直接従う。
従って系の最終statementはrank≤2全体を覆うが、K2を直接適用するのはactive rank-2だけである。
これは依存関係上、一般閉包の open 補題を使わない帰結であり、R-K2-FRESH R3 PASS。
(注: これは閉包定理ドラフト §4 の L2a(多項式 × e^{(1−δ)|z|²/2+R|z|})より真に弱い弱形だが、
そちらの下流で envelope が効く唯一の箇所(§5 一様可積分尾部)には十分。)
