## 1. 設定と主張

F(t) = P(t)e^{q₁(t)} + c₂e^{q₂(t)}(t 実変数、P ≢ 0 複素多項式 deg P ≤ 2、c₂ ≠ 0、
q₁ ≠ q₂ 複素 2 次多項式)。重み (2,1) = 閉包ドラフトの導来原子 deg P ≤ 2(m−1)、m = 2 に対応。
- 包絡: m₁(t) := log|P(t)| + Re q₁(t)(値域 [−∞,∞))、m₂(t) := log|c₂| + Re q₂(t)、
  V := max(m₁, m₂)(> −∞)。
- I 長さ 1、J ⊆ I 長さ ε ∈ (0,1]、Λ := max_j sup_I |q_j′|、A := sup_I V − sup_J V ≥ 0。
- (P1)′ 自明上界: |F| ≤ e^{m₁} + e^{m₂} ≤ 2e^{V} pointwise(P の零点では m₁ = −∞ として成立)。

**予想 K2Q**: sup_I|F| ≤ C₀ ε^{−4} e^{A+Λε} sup_J|F|(C₀ 絶対定数)。
ε^{−4} は必要(§2)。base の周波数非依存性(Λ は指数の Λε のみ)は K2 と同じ要求 —
chaining C′ が kernel に要求する形((γ,κ) = (4,1))。

## 2. 退化テスト(ε^{−4} の必要性と障害の registry — 検算済み)

**(T1) 衝突退化 ⇒ Γ ≥ 4(ε^{−4} は必要)**: p := q₁ − q₂ → 0 の族で
P := −c₂·[e^{−p} の deg ≤ 2 切断] と選ぶと F = c₂(e^{p} − [切断])e^{q₁}·e^{−p} 型 ~
c₂(p²/2 + O(p³))e^{q₂}。p = τt²(τ → 0)なら F/e^{q₂} ≈ c₂τ²t⁴/2 — **実 4 次多項式**。
deg 4 Chebyshev 配置(J 中央、I 端)で比 ~ 648/ε⁴(補題 E4)、包絡は平坦(A, Λε → 0)。
⇒ γ = 4 未満は不可能。これは閉包側 sharp test (1−e^{τt²})² ~ τ²t⁴(Γ(3) ≥ 4)の (2,1) 版。

**(T2) 単一零点 dip(γ ≥ 3 の別機構)**: P = (t−x₀)²(実重根、x₀ ∈ I∖J、dist(x₀,J) = d)、
p := iπ − [2log(t−x₀) の J 中心での 2-jet]。J 上 u := log P + p − iπ = O(ε³/d³)(Taylor 剰余、
|(2log)‴| ≤ 4/d³)⇒ σ_H ~ ε³/d³。一方 t = x₀ で P = 0、H = 1。比 ~ d³/ε³ ≤ ε^{−3}(d ≤ 1)。
教訓: **J 上の平坦性は I へ延長できない**(u は零点で −∞ へ発散)— K2 場合 (c) の
「u 小 on I」戦略は零点近傍で構造的に破綻する。ただし比自体は ε^{−4} 予算内。

**(T3) 対称 2 零点(ε^{−4} 飽和の第 2 機構)**: 零点 z₁, z₂ を J 中心 t_J に対し対称
(z₂ = 2t_J − z₁、距離 d)に置くと u‴ = 2[(t−z₁)^{−3} + (t−z₂)^{−3}] は t_J で 0(奇対称)、
u の J 上平坦性は 4 階から: |u⁗| ~ 12/d⁴ ⇒ σ_H ~ ε⁴/d⁴。dip で |H| ~ 1 ⇒ 比 ~ d⁴/ε⁴、
d ~ 1 で **ε^{−4} を飽和**。⇒ C₀ε^{−4} が sharp 候補(T1 と独立の機構で一致 — 傍証)。

## 3. 正規化と基本不等式(K2 からの継承 — 証明済み)

H := F/(c₂e^{q₂}) = 1 + P̃(t)e^{p(t)}、P̃ := P/c₂、p := q₁ − q₂。
φ̃ := log|P̃| + Re p = m₁ − m₂(値域 [−∞,∞))。P̃ ≠ 0 の点で ψ̃ := arg(P̃e^{p}) の連続分岐。
(P2)′ |H| ≥ |e^{φ̃} − 1|。 (P3)′ |H| ≥ e^{φ̃}|sin ψ̃|。 (P4)′ cos ψ̃ ≥ 0 なら |H| ≥ 1。
(いずれも K2 の (P2)–(P4) と同一の初等計算。P̃ = 0 の点は e^{φ̃} = 0 として (P2)′ が |H| = 1 を返す。)
σ := sup_J|F|、σ_H := sup_J|H|、t₂ := argmax_J|H|。osc_J m₂ ≤ Λε(|m₂′| = |Re q₂′| ≤ Λ)。
**注意: osc_J m₁ ≤ Λε は成立しない**(log|P| の寄与)— K2 との第 1 の差異。以下の場合分けは
純指数原子 m₂ 側で正規化することでこれを回避する。

**補題 E4(deg 4 Chebyshev 外挿)**: 実多項式 g(deg ≤ 4)が長さ ε の J 上 |g| ≤ μ なら、
J を含む長さ 1 の I 上 |g| ≤ 648μ/ε⁴。
*証明*: affine で J → [−1,1]、I ⊆ {|x| ≤ 3/ε}。Chebyshev 極値性で |g(x)| ≤ μ|T₄(x)|、
|x| ≥ 1 で |T₄(x)| = |8x⁴−8x²+1| ≤ 8x⁴ ⇒ |g| ≤ 8μ(3/ε)⁴ = 648μ/ε⁴。∎

## 4. 場合 (a)(b): 深い相殺がない場合(証明済み)

**場合 (a) sup_J φ̃ ≥ 1**(quasipolynomial 項が J 上どこかで支配): t_a := argmax_J φ̃
(φ̃ は J 上上半連続 + 実解析的(−∞ 点除く)で sup 達成; sup_J φ̃ ≥ 1 > −∞ なので t_a は零点でない)。
(P2)′: |F(t_a)| = e^{m₂(t_a)}|H(t_a)| ≥ e^{m₂(t_a)}(e^{φ̃(t_a)}−1) ≥ (1−e^{−1})e^{m₁(t_a)}。
J 上の包絡: m₁(t) = φ̃(t) + m₂(t) ≤ φ̃(t_a) + m₂(t_a) + Λε = m₁(t_a) + Λε(φ̃ の最大性 +
osc_J m₂ ≤ Λε)。m₂(t) ≤ m₂(t_a) + Λε ≤ m₁(t_a) + Λε(φ̃(t_a) ≥ 1 > 0)。
⇒ sup_J V ≤ m₁(t_a) + Λε ⇒ σ ≥ 0.63 e^{−Λε}e^{sup_J V}。
(P1)′: sup_I|F| ≤ 2e^{A}e^{sup_J V} ≤ **3.2 e^{A+Λε} σ**。∎(a)
(K2 の場合 (a) より単純化された — 正規化を純指数原子側に取ったため。)

**場合 (b) sup_J φ̃ ≤ 1 かつ σ_H ≥ 1/10**: J 上 pointwise V ≤ m₂ + max(0, φ̃) ≤ m₂ + 1 より
sup_J V ≤ sup_J m₂ + 1 ≤ m₂(t₂) + Λε + 1。σ ≥ |F(t₂)| = e^{m₂(t₂)}σ_H ≥ (1/10)e^{sup_J V − 1 − Λε}。
(P1)′: sup_I|F| ≤ 2e^{A}e^{sup_J V} ≤ **55 e^{A+Λε} σ**。∎(b)(K2 場合 (b) と同一。)

## 5. 場合 (c): 深い相殺 sup_J φ̃ ≤ 1, σ_H < 1/10(核心 — open)

### 5.1 継承する平坦性データ(証明済み — K2 (c1)(c2) と同一計算)

- (c1)′ (P2)′ ⇒ |e^{φ̃}−1| ≤ σ_H ⇒ |φ̃| ≤ 1.2σ_H on J。特に e^{φ̃} ≥ 0.88 > 0 ⇒
  **P̃ は J 上零点なし**、ψ̃ は J 上連続。
- (c2)′ (P4)′ ⇒ cos ψ̃ < 0、(P3)′ ⇒ |sin ψ̃| ≤ 1.14σ_H ⇒ 分枝 k₀ 一定で
  |ψ̃ − (2k₀+1)π| ≤ 1.8σ_H on J。
- u := φ̃ + i(ψ̃ − (2k₀+1)π)(= log(P̃e^{p}) の分枝 − iπ(2k₀+1))は J 上 |u| ≤ 3σ_H、
  H = 1 − e^{u}。

### 5.2 u の構造剛性(検算済み事実)

u は「複素 2 次多項式 + Σ_{i≤2} log(t−z_i) + 定数」の族(z_i = P̃ の零点、≤ 2 個; 8 実パラメタ)。
**u‴(t) = 2 Σ_i (t−z_i)^{−3}**(p‴ = 0; 極 ≤ 2 個の明示有理関数)。
u⁗(t) = −6 Σ_i (t−z_i)^{−4}。K2(P 定数)では u は 2 次多項式で u‴ = 0 — 本拡張の新規部分は
この log 特異性の処理に完全に局在する。

### 5.3 攻略アーキテクチャ(設計 — 未証明)

零点距離 d_i := dist(z_i, I) による 2 分岐(閉包 §4.3.5.3 の split-scale Taylor と同型の発想):

**(far) 全零点が遠い(d_i ≥ c₀)**: I 上 |u^{(5)}| ≤ 48/c₀⁵ 有界 ⇒ u は I 上 deg 4 Taylor +
一様剰余で近似され、J 上 |u| ≤ 3σ_H から補題 E4 で sup_I|u の 4 次近似| ≤ Cσ_H/ε⁴、
剰余は加法的 ⇒ sup_I|H| ≤ C(σ_Hε^{−4} + 剰余)。剰余項が σ_H に劣後する条件の精密化が要る
(σ_H が剰余より小さい regime では H の主要部が Taylor 剰余で決まり、別途下界議論)。

**(near) 零点が近い(d_i < c₀)**: 平坦性の延長は不可能(T2)だが、零点の存在自体が
σ_H の下界を強制する: u の log 特異性は J 上で deg 4 多項式に ε⁵/d⁵ 精度でしか
近似できない(T2/T3 の逆向き評価)⇒ σ_H ≳ ε^{k}/d^{k}(k = 3 or 4、配置依存)。
このとき dip 側の |H| ≤ 1 + e^{φ̃} は (P1)′ 経由で e^{V} に吸収され、比は ε^{−4} 予算内
(T2/T3 の勘定と整合)。**未処理**: 複素零点(u⁗ の符号性が失われる)、2 零点の一般配置
(near + far 混在)、near-zone と far-zone の接続(J が零点を挟む場合は k₀ 分枝が
zone 間で π 跳ぶ — winding の帳簿)。

### 5.4 open 問題リスト(執筆順)

1. (far) 枝の完全証明: 剰余 vs σ_H の 2 regime 分割と定数追跡。
2. (near) 枝の下界補題: 「log 特異性の deg 4 近似誤差下界」の一様版(複素零点込み)。
   候補ツール: u‴ の明示式から divided difference / 有限差分での下界抽出(零点勘定不使用 —
   chirp 教訓により複素解析は避ける)。
3. 混在配置の接続と winding 帳簿。
4. 定数の総和と C₀ の確定、数値検証(K2 と同じ ~10⁴ 配置プロトコル)。

## 6. chaining への接続(確認済みメモ)

C′(radial chaining)は kernel を (γ,κ) 抽象で受けるため、K2Q が閉じれば kernel(2,1) =
(γ,κ) = (4,1) として即座に L2a′ の (2,1) 版が従う。ray 制限 f(se^{iθ}) は P(se^{iθ}) が
s の deg ≤ 2 多項式になるので class は閉じている(検算済み)。
